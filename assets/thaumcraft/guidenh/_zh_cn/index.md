**神秘时代**（Thaumcraft 4，简称 TC4）是 GTNH 的主要魔法模组之一，也是你第一个接触到的魔法模组。

从扫描、研究开始，你会逐渐掌握物品与生物中蕴含的要素，通过炼金和注魔，制作法杖、魔法工具、装备和自动化设施。

在 NH 中，神秘时代也与科技材料、暮色森林和其他魔法模组联系紧密。随着研究深入，你可以接触植物魔法、血魔法等内容，也能将魔法设施接入 AE 系统，或利用魔法为 GT 机器提供维护等功能。

本页介绍神秘时代的世界、基础概念和 NH 特化内容。第一次接触时，先认识魔导手册，并分清<Color color="#B7A0D6">研究点、Vis 和源质</Color>。

<br clear="all" />

## 神秘时代的世界

- **万物皆有要素。** 在神秘时代中，物体不仅有外形和用途，也具有能够被观察与研究的<Color color="#B7A0D6">要素</Color>。火、水、秩序、生命、金属等概念，都能用要素来描述。不同要素的组合构成了更复杂的属性；理解这些关系，是研究和炼金的基础。

- **知识逐渐变成设施。** 世界中还存在汇聚魔力的<Color color="#B7A0D6">灵气节点</Color>。法杖可以从节点中抽取 Vis，供奥术合成和法杖核心使用；从物品中提取出的源质，则用于炼金、注魔和部分魔法设备。随着知识和设施不断完善，你会从手工研究与合成，逐渐发展到源质储存、物流和自动化生产。

- **探索也会带来后果。** 处理魔法材料可能污染周围环境，接触禁忌知识则可能给玩家带来扭曲。研究新的能力时，需要同时了解它的用途、消耗和影响。

神秘时代的基本学习过程可以概括为：

> **观察与扫描** → 发现要素、取得研究点  
> **完成研究** → 准备材料与魔力  
> **制作与使用** → 建立新的魔法设施

## 魔导手册

<ItemLink id="Thaumcraft:ItemThaumonomicon" showIcon="left" />是神秘时代的主要知识入口。手持右键打开后，可以查看已经发现的研究、阅读说明、取得研究笔记，以及查阅解锁后的配方。

手册按不同主题和附属模组分成多个标签页。研究之间存在前置关系，部分研究还需要特定的扫描或其他条件才能出现。因此，**没有看到某项研究，并不一定意味着它不存在**。

| 手册中的内容 | 阅读要点 |
| --- | --- |
| 研究图标与连线 | 查看研究之间的关系，并阅读图标上的提示 |
| <Color color="#B7A0D6">研究笔记</Color> | 按提示准备纸和笔与墨，取得笔记后在研究台完成连线 |
| 消耗研究点的研究 | 核对所需要素及研究点，满足条件后解锁 |
| 已完成的研究 | 打开说明，确认设备用途、操作方式和配方 |
| <Color color="#D5B77A">禁忌知识标记</Color> | 紫色效果与相应提示表示学习它可能带来扭曲 |

完成研究笔记后，还需要阅读完成的研究成果，才能真正学会相应内容。**研究解锁和取得制作材料也是两个步骤**：手册中能看到配方时，你的科技和魔法设施仍可能不足以制造它。

## 要素、研究点、Vis 与源质

这些概念经常使用相同的要素图标，但用途不同。看见同一个图标时，先确认它出现在研究台、法杖还是源质容器中。

| 概念 | 含义 | 主要用途 |
| --- | --- | --- |
| <Color color="#B7A0D6">要素（Aspect）</Color> | 描述物品、生物和魔法现象的属性 | 判断研究中的组合关系，以及物品可提供哪些源质 |
| <Color color="#B7A0D6">研究点</Color> | 玩家积累的、按要素分类的研究资源 | 研究台连线、组合要素和解锁部分研究 |
| <Color color="#B7A0D6">Vis</Color> | 法杖中按元始要素分别储存的魔力 | 奥术工作台合成、使用法杖核心等 |
| <Color color="#B7A0D6">源质（Essentia）</Color> | 从物品中提取、可储存和运输的要素 | 炼金、注魔及部分魔法设备 |

### 要素与研究点

六种<Color color="#B7A0D6">元始要素</Color>是 <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"aer"}' scale="0.75" />风（Aer）、<ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"terra"}' scale="0.75" />土（Terra）、<ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"ignis"}' scale="0.75" />火（Ignis）、<ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"aqua"}' scale="0.75" />水（Aqua）、<ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"ordo"}' scale="0.75" />秩序（Ordo）和 <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"perditio"}' scale="0.75" />混沌（Perditio）。复合要素由两种其他要素组合而成；NH 的附属模组还会扩展要素体系。

扫描物品、生物等对象，可以发现要素并取得研究点。部分对象需要先认识其组成要素才能扫描；研究台中的要素组合也能帮助你发现新的复合要素。研究点不足时，需要补充研究资源，给法杖充能不能解决这个问题。

### Vis 与源质

法杖中的 Vis 按六种元始要素分别记录。奥术合成需要哪些要素，就要检查法杖中对应的储量；某一种已经充满，并不能补足另一种的缺口。

源质则通常通过炼金炉等设施从物品中提取，并收集到罐子等容器中。配方需要金属、生命等复合要素时，往往是在要求对应的源质，而不是法杖中的 Vis。

例如，奥术工作台缺少风 Vis 时，应给法杖补充风要素魔力；注魔缺少金属源质时，应准备含有该要素的原料并提取源质。**研究点、法杖 Vis 和罐子中的源质，需要分别准备。**

## 节点与魔力来源

**灵气节点**是世界中的魔力集中点。使用观察工具可以了解节点包含的要素，再用法杖从中抽取 Vis。多数节点的魔力会逐渐恢复，因此寻找和管理节点是早期供能的重要工作。

节点有不同的类型、质量和要素组成。认识节点之后，还可以研究搬运、保存和改造的方法，把探索所得用于基地中的魔法设施。

> [!WARNING]
> 早期法杖从节点抽取魔力时，不要随意把某种要素抽到零。<Color color="#D5B77A">抽干节点</Color>可能造成损伤，影响它之后提供魔力的能力；应先了解自己的法杖和已完成研究能提供哪些保护。

后续还会接触<Color color="#B7A0D6">厘魔（Centi-Vis）</Color>：改造后的节点可以为相应设备提供这种供能。使用法杖储存的 Vis 和建设厘魔供能网络，是需要分别理解的两种供能方式。

## 魔力消耗与减免

<Color color="#B7A0D6">法杖容量</Color>决定每种元始要素最多能储存多少 Vis；<Color color="#B7A0D6">魔力减免</Color>则降低相应操作实际消耗的 Vis。杖端和部分装备可以提供消耗折扣，制作更高要求的物品时，需要同时考虑法杖容量和可用减免。

以奥术合成为例，假设某一种要素的基础需求为 100 Vis，适用于该合成的总减免为 20%，则该要素的实际需求为 80 Vis。这可以让容量为 80 的法杖满足原本要求 100 的配方，但法杖本身的容量仍然是 80。

| 遇到的问题 | 检查方向 |
| --- | --- |
| 法杖容量足够，但当前魔力不足 | 补充配方要求的每一种 Vis |
| 法杖充满后仍无法满足配方 | 升级法杖，或增加适用于该合成的魔力减免 |
| 装备已有减免，仍无法制作 | 核对实际需求、装备是否穿戴，以及法杖中各要素的储量 |
| 注魔缺少源质 | 准备源质供给；Vis 减免不能替代源质原料 |

## 咒波、腐化与扭曲

神秘时代中，环境问题和玩家自身受到的影响需要分开理解。

| 概念 | 主要影响对象 | 认识要点 |
| --- | --- | --- |
| <Color color="#D5B77A">咒波（Flux）</Color> | 周围环境 | 不当的魔法处理可能释放污染，应关注炼金设施及其周围情况 |
| <Color color="#D5B77A">腐化（Taint）</Color> | 地形、方块与生物 | 是需要专门处理的环境危害，发现后应及时了解来源和治理方法 |
| <Color color="#D5B77A">扭曲（Warp）</Color> | 玩家自身 | 禁忌研究和部分行为会带来扭曲，并引发相关事件 |

清理环境污染不能消除玩家的扭曲，处理扭曲也不能代替对腐化区域的治理。阅读新研究时，留意禁忌知识提示；准备新的炼金设施时，则要考虑污染控制。

> [!WARNING]
> NH 中的 Warp Theory 增加了扭曲事件，<Color color="#D5B77A">高扭曲</Color>时可能出现会破坏基地的危险事件。深入禁忌研究前，应了解事件与应对方法，并为贵重设施和物品做好安排。

## NH 特化与模组联动

NH 对神秘时代的材料路线、研究与使用体验进行了许多调整。阅读教程和制作物品时，可以重点留意以下几类内容。

| 内容 | NH 中需要留意的地方 |
| --- | --- |
| 法杖材料 | 常规法杖路线与暮色森林 Boss 材料有关；制作前核对当前配方与材料来源 |
| 法杖升级 | 容量和 Vis 减免需要共同发展；完成相关研究后，还可以更换杖芯和杖端 |
| 配方查询 | 魔导手册用于阅读研究与操作说明，NEI 用于核对当前配方；任务书明确提醒部分法杖配方应查看 NEI |
| 扫描便利功能 | 可以在背包中扫描物品；整箱扫描还需要完成相应研究 |
| 研究与要素辅助 | Aspect Recipe Index 等内容帮助查询要素来源、组合与相关配方 |
| 魔法自动化 | 傀儡、Automagy 等内容提供物流和自动化设施；魔法 AE 可以接入源质储存与供给 |
| 科技与魔法联动 | EMT 等附属提供相关工具和设备；GT 中还有研究完成机、Vis 自动维护仓等设施 |
| 其他魔法路线 | 植物魔法、血魔法等内容也与神秘研究及材料存在联系 |

魔法提供的收益包括移动和建造工具、装备与附魔、耐久修复、材料加工，以及物品和源质的自动化。可以根据眼前的需求选择研究方向，再沿着前置条件逐步完善设施。
