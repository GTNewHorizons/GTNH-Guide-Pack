神秘时代的研究从认识事物开始.扫描让你发现物品、生物与节点所包含的<Color color="#B7A0D6">要素</Color>,取得研究点和线索；<br>研究台则把这些收获用于要素组合与研究笔记,最终成为魔导手册中的知识.

研究中最容易混淆的是**认识要素、获得研究点和完成研究**.本页分别介绍这些条件,以及 NH 提供的扫描与研究便利功能.

## 要素体系与组合关系

**要素（Aspect）**既是物体的魔法属性,也是研究中的分类依据.六种元始要素构成整个体系的基础,其他复合要素由两种要素组成；<br>组成要素本身也可以是复合要素,因此要素之间形成逐层展开的关系网.

六种元始要素是 <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"aer"}' scale="0.75" />风（Aer）、<ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"terra"}' scale="0.75" />地（Terra）、<ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"ignis"}' scale="0.75" />火（Ignis）、<ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"aqua"}' scale="0.75" />水（Aqua）、<ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"ordo"}' scale="0.75" />秩序（Ordo）和 <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"perditio"}' scale="0.75" />混沌（Perditio）.

| 复合要素 | 组成要素 |
| --- | --- |
| <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"lux"}' scale="0.75" />光明（Lux） | <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"aer"}' scale="0.75" />风 + <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"ignis"}' scale="0.75" />火 |
| <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"motus"}' scale="0.75" />移动（Motus） | <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"aer"}' scale="0.75" />风 + <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"ordo"}' scale="0.75" />秩序 |
| <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"victus"}' scale="0.75" />生命（Victus） | <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"terra"}' scale="0.75" />地 + <ItemImage id='aspectrecipeindex:aspect:1:{Aspect:"aqua"}' scale="0.75" />水 |

**要素的组成关系与物品的要素含量,是两种不同的信息.** “生命由地与水组成”说明研究中的关系；“某物品包含生命”说明这个物品的性质.后者会影响扫描所得和源质原料选择,却不表示研究台会把这个物品直接消耗成研究点.

同样,研究台中组合地与水,得到的是生命研究点；炼金炉处理包含生命要素的物品,得到的则是生命源质.两者使用同一个要素图标,但资源的记录位置和用途不同.

NH 的附属模组还会增加要素.认识新要素时,应结合其名称、组成与实际来源,不应把原版 Wiki 中的要素总数视为当前整合包的总数.

## 扫描能获得什么

<ItemLink id="Thaumcraft:ItemThaumometer" showIcon="left" />用于观察物品、方块、生物和灵气节点的魔法性质.扫描的主要收益有三类：

|  |  |
| --- | --- |
| 认识对象的要素 | 揭示对象包含的要素及数量,也可能发现尚未认识的要素 |
| 研究点 | 按要素分类记录在玩家身上,供研究台消耗 |
| 研究线索 | 某些特定对象能够揭示隐藏研究,扩大魔导手册中的研究范围 |

这三类收获不完全相同.扫描一个已经认识其要素的新物品,仍可以补充研究点；为了隐藏研究扫描特定对象,关注的则是研究线索.

**扫描不消耗被观察的物品,也不会将它分解为源质.** 扫描普通物品与使用炼金炉处理原料,分别属于取得知识与生产魔法资源.

扫描记录与研究点属于玩家的研究资料.同一种已经完成扫描的对象,不能通过反复扫描无限取得点数.

## 世界扫描、背包扫描与整箱扫描

世界中的方块、掉落物和生物,可以通过手持魔导透镜观察.NH 还提供了背包扫描与整箱扫描,为研究点获取提供了便利.

 - 世界扫描 | 魔导透镜对准世界中的有效对象,持续观察
 - 背包扫描 | 光标拿着魔导透镜,停留在背包或容器中的物品格上
 - 整箱扫描 | 完成容器扫描研究后,对容器使用魔导透镜

容器扫描研究位于魔导手册的基础信息分类,以解构台研究为前置；它本身需要完成研究.<br>
NH 任务书的“Scanning Made Easy”介绍了这两项便利功能.整箱扫描使用潜行与右键；只扫描箱子方块本身,与扫描箱内物品,也应分别理解.<br>

背包扫描并不适用于所有界面中的所有格子,例如AE2,扫描元件需要另一个物品:<ItemLink id="thaumicenergistics:cell.microscope" showIcon="left" />

## 未知要素与扫描条件

魔导透镜提示“无法理解”时,常见原因是对象包含了尚未认识的复合要素.<br>研究者需要已经认识这个要素,或认识构成它的两个要素,才能理解相关对象.<br>复杂对象可能同时涉及多种复合要素,因此扫描是否成功,取决于要素的发现情况.

研究台中的要素组合也是发现新复合要素的途径.正确的组合要素,可以让玩家认识这个新要素,并获得一定数量的研究点；随后能理解的扫描对象也会扩大.

> [!NOTE]
> 任意两种要素并不一定能形成有效组合.尝试无效组合也会消耗研究点,因此要素关系应先结合已知资料查询,避免反复猜测消耗研究资源.

扫描顺序因此会影响探索进展,任务书的“Just Tell Me What to Scan Already!”提供了一组扫描对象作为参考.

## 物品要素与 NEI 查询

已经扫描的物品,可以在物品提示中查看要素及数量.默认情况下,按住潜行键（通常为 Shift）显示这些信息.<br>未知图标、已经认识的要素与具体数量,分别表示不同的发现状态和要素含量.

在GTNH中,已扫描物品可以在NEI显示提供要素、要素组合、含有某要素的物品,以及奥术、炼金和注魔配方查询,适合查询量产源质来源.

## 研究点的来源与消耗

<Color color="#B7A0D6">研究点</Color>按要素种类分别记录.研究台中的数字是玩家可用的研究资源.<br>某种复合要素已经被认识,但它的研究点用完时,便无法继续用它放置连线.

| 来源 | 提供什么 | 限制与特点 |
| --- | --- | --- |
| 扫描新的有效对象 | 对象所含要素对应的研究点；首次发现要素还有额外收获 | 已经扫描过的同种对象不能反复提供点数 |
| 研究台组合要素 | 对应复合要素的研究点 | 消耗两个组成要素的研究点,不是无成本产生资源 |
| 知识碎片 | 使用时为每种元始要素增加 1～2 点 | 获取困难,而且是一次性消耗品 |
| 解构工作台 | 消耗物品,尝试取得元始要素研究点 | 复合要素会被拆解,产出较慢,概率较低 |
| 研究台的环境加成 | 环境产生的少量备用研究点 | 取得缓慢,不能代替稳定的研究点来源 |

**知识碎片**既可以补充基础研究资源,也与失落知识的发现有关.其两种用途应分别理解；想寻找特殊研究时,需要查阅手册中的知识碎片条目.

NH 默认对扫描收益设有研究点软上限：某种要素已有的研究点达到 500 后,继续扫描取得的该要素点数会减少.

研究点主要用于放置笔记中的要素、组合复合要素,以及复制研究成果.使用复合要素较多时,还要关注其组成要素的储量,避免最后只能取得一种研究点,却无法补充需要的其他种类.

## 研究台、研究笔记与笔墨

<ItemLink id="Thaumcraft:ItemThaumonomicon" showIcon="left" />展示可研究的方向,研究台处理笔记与要素,<ItemLink id="Thaumcraft:ItemInkwell" showIcon="left" />提供书写所需的笔墨.

| 内容 | 用途 |
| --- | --- |
| 魔导手册中的研究条目 | 查看前置、取得能够研究的笔记、查阅已经解锁的知识 |
| 未完成的研究笔记 | 记录某项研究的题目与需要连接的要素 |
| 研究台 | 组合要素、处理笔记、进行已解锁的研究辅助操作 |
| 笔与墨 | 取得笔记和研究台书写时使用的工具；墨水会被消耗 |
| 已完成的研究成果 | 阅读后,将对应研究加入玩家的知识进度 |

取得研究笔记与在研究台中书写,都需要笔墨.建议做两套笔墨,用于获取笔记与连线.<br>
**GTNH锁定困难研究设定,常规研究的条目也需要通过笔记完成.** 

Thaumcraft Research Tweaks 改写了研究台界面.要素之间可以通过拖放组合,也可以在拖动时使用右键；向笔记格中书写要素也使用相应方式.<br>
手册中的研究说明已补充这些界面功能,查看时应以当前界面为准.

## 研究笔记的连线规则

笔记使用六边形格子表示要素之间的联系.完成条件是让题目中给出的要素通过有效连接形成一个连通整体.

一个复合要素可以与它的组成要素连接,组成要素也可以与由它构成的复合要素连接.名称相近、图标颜色相近,或都能追溯到某种元始要素,并不自动构成直接连接.

例如,地与水之间没有因为都很基础而产生直接关系,但生命由地与水组成,因此“地—生命—水”可以表达两段有效关系.<br>另一种情况是光与运动都由风参与构成,“光—风—运动”则借共同的组成要素连接两者.

组成关系与位置条件需要同时满足,只有相邻且有关系的要素才能互相连接.

放置要素会消耗对应研究点,书写和修改还会消耗墨水.通常移除放错的要素不会返还研究点；解锁研究专长或研究精通后,有机会返还.

笔记全部连通后,会成为已完成的研究成果.**完成连线之后需阅读成果,才能解锁对应研究.**

## 研究前置与隐藏知识

魔导手册中的连线表示研究之间的前置关系,但并不是所有条件都会仅靠一条连线完整展示.<br>
某些内容还要求特定扫描、先前的发现、扭曲相关事件,或其他模组的研究进度.

> [!WARNING]
> 带有<Color color="#D5B77A">禁忌知识</Color>提示的研究阅读后会增加扭曲.危险程度代表增加的扭曲类型与数量

## 常见问题

| 现象 | 检查方向 |
| --- | --- |
| 魔导透镜无法理解某个对象 | 检查其要素的发现情况,尤其是尚未认识的复合要素及其组成 |
| 反复扫描同种物品没有新点数 | 该类对象可能已经扫描；继续增加同种物品数量不会变成新的发现 |
| 新扫描所得比物品要素数量少 | 某种研究点库存较高时会触发扫描收益的软上限 |
| 背包扫描没有反应 | 确认光标拿着魔导透镜、停留时间足够,目标为普通有效库存格 |
| 能扫描单件物品,但不能扫描整箱 | 检查容器扫描研究是否完成,并区分箱子方块与箱内物品 |
| 已认识某种要素,却不能在笔记中放置 | 检查对应研究点余量、笔墨和目标格子的状态 |
| 组合要素后基础点数减少 | 组合会消耗组成要素；无效组合也可能造成浪费 |
| 图标相邻却没有连接 | 必须存在直接的组成关系,不能只凭名称或图标判断 |
| 研究笔记已经完成,手册仍未解锁 | 检查是否阅读了已完成的研究成果 |
| NEI 中找不到某个要素来源 | 查询受到扫描与发现进度影响,列表不等于全部可能来源 |
