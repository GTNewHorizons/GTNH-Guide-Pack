# 标题覆盖层

标题与副标题文字显示已经从更高版本回移植到 1.7.10，现在已经能在 NTNH 里使用了！

服务器管理员现在可以通过 `/title` 在玩家屏幕上显示标题和副标题文本。

标题还支持淡入、停留和淡出时间设置，可以通过 `/title <player> times <fadeIn> <stay> <fadeOut>` 分别配置。
