# 大型蒸汽锻造锤

<GameScene interactive={true} wrap="square" align="right" width="320" height="280">
  <ImportStructureLib controller="gregtech:gt.blockmachines:31083" tier={1} />
</GameScene>

<ItemLink id="gregtech:gt.blockmachines:31083" showIcon="left" />（Steam Presser），是蒸汽阶段的多方块锻造锤。它使用蒸汽批量处理矿石和材料，可以代替单方块蒸汽锻造锤进行制板、合成长杆等加工，最多同时执行 8 份相同配方。

机器有普通青铜结构和高压钢结构两个等级，使用同一个控制器。升级高压结构可以提高产能，但不会提高可加工配方的等级。

| 项目 | 说明 |
| --- | --- |
| 解锁阶段 | 蒸汽；控制器配方需要铸铁板、铁砧和铜金合金框架等材料 |
| 结构尺寸 | 占地 5×5，高 7 格；控制器位于正面第二层中央 |
| 供能 | 恰好 1 个蒸汽仓，不使用能源仓 |
| 配方范围 | 锻造锤配方，限 LV 及以下，即配方需求不超过 32 EU/t |
| 并行 | 最多 8 份相同配方；高压结构不增加并行上限 |
| 加工加成 | 普通结构相对单方块青铜蒸汽锻造锤有 125% 运行速度、62.5% 的每并行蒸汽消耗速率 |
| 升级与超频 | 高压结构使速度和蒸汽消耗速率翻倍；没有电压超频 |
| 维护与污染 | 不需要维护，不产生污染，也不需要消声仓 |

### 结构材料

下面按一个蒸汽仓、一个输入总线和一个输出总线的基础配置备料。普通结构使用镀铜砖块、青铜管道方块和铁块，高压结构使用对应钢制部件；**同一台机器的三类结构部件必须属于同一等级**。

| 部件 | 普通结构 | 高压结构 | 数量与位置 |
| --- | --- | --- | --- |
| 外壳 | <ItemLink id="gregtech:gt.blockcasings:10" showIcon="left" /> | <ItemLink id="gregtech:gt.blockcasings2:0" showIcon="left" /> | 基础配置 39 个；可替换为仓室或总线，但至少保留 35 个真正的外壳 |
| 管道方块 | <ItemLink id="gregtech:gt.blockcasings2:12" showIcon="left" /> | <ItemLink id="gregtech:gt.blockcasings2:13" showIcon="left" /> | 2 个，第六层和第七层中央 |
| 金属块 | <ItemLink id="minecraft:iron_block" showIcon="left" /> | <ItemLink id="gregtech:gt.blockmetal6:13" showIcon="left" /> | 2 个，第四层和第五层中央 |
| 控制器 | <ItemLink id="gregtech:gt.blockmachines:31083" showIcon="left" /> | 同一控制器 | 1 个，正面第二层中央 |
| 蒸汽仓 | <ItemLink id="gregtech:gt.blockmachines:31040" showIcon="left" /> | 同一仓室 | 恰好 1 个，替换一个外壳位置 |
| 输入总线 | <ItemLink id="gregtech:gt.blockmachines:31046" showIcon="left" /> | 同一总线 | 至少 1 个，替换外壳位置 |
| 输出总线 | <ItemLink id="gregtech:gt.blockmachines:31047" showIcon="left" /> | 同一总线 | 至少 1 个，替换外壳位置 |
| 流体输入仓 | 例如 <ItemLink id="gregtech:gt.blockmachines:51" showIcon="left" /> | 同一仓室 | 可选，替换外壳位置；用于输入配方要求的流体，例如矿物作物加工所需的酸液 |

结构共有 42 个可放外壳或仓室的位置。安装三个必需接口后，剩下 39 个外壳；再安装一个流体输入仓后，剩下 38 个。增加仓室或总线时至少保留 35 个真正的外壳。管道方块和金属块不能换成仓室或总线。

### 逐层放置

层数从底座向上计算。先确定控制器朝向，再照交互结构或投影逐层搭建；**底座正面比控制器向前伸出一格**，不要把控制器放到最前面的底座边缘。

| 层数 | 放置内容 |
| --- | --- |
| 第一层 | 铺 5×5 底座，四个角不放方块，共 21 个外壳位置 |
| 第二层 | 放控制器，并按投影布置周围的 9 个外壳位置 |
| 第三层 | 在左右两侧各放一个外壳位置，开始向上搭支柱 |
| 第四、第五层 | 继续两侧支柱，并在每层正中央各放一个铁块；高压结构改用钢块 |
| 第六层 | 按投影放 6 个外壳位置，在正中央放第一个管道方块 |
| 第七层 | 在第一个管道方块正上方放第二个管道方块 |

投影中的空位不用补成实心外壳。蒸汽仓和蒸汽专用输入、输出总线可安排在底部外壳位置，方便管道连接；普通电力机器的物品总线不能代替蒸汽专用总线。

使用 <ItemLink id="structurelib:item.structurelib.constructableTrigger" showIcon="left" /> 可以查看结构投影并辅助搭建。投影仪的主信道等级 1 对应普通结构，等级 2 对应高压结构；辅助搭建后仍需安装仓室、检查结构。

## 机器用途

大型蒸汽锻造锤使用锻造锤配方表。查看 NEI 时，先确认物品确实有锻造锤配方，再检查配方等级、输入数量和产物。

| 用途 | 常见加工与注意事项 |
| --- | --- |
| 制作金属板 | 许多早期金属可用 3 个锭制作 2 个板；并行只增加一次加工的份数，不改变材料比例 |
| 合成长杆 | 适用材料可用 2 个杆制作 1 个长杆，具体材料和等级以 NEI 为准 |
| 破碎矿石 | 将有对应配方的矿石处理为粉碎矿石或宝石；产物随矿种变化，不是所有矿石都会变成同一种中间产物 |
| 矿物处理收尾 | 将适用的离心矿石处理为粉；研磨路线可能另有副产物，选择前先比较 NEI 中的完整产物列表 |
| 矿物作物加工 | 配合流体输入仓处理有 LV 及以下锻造锤配方的 CropsNH 收获物，制取纯净粉碎矿石或含杂粉 |

机器只负责锻造锤这一步，不会自动完成洗矿、离心或后续冶炼。安排矿物处理线时，应按实际产物分流，避免把需要继续处理的中间产物直接送去烧制。

> [!NOTE]
> “蒸汽阶段可以取得机器”和“最高处理 LV 配方”是两件事。机器始终以蒸汽供能；换成高压钢结构也不能执行 MV 或更高等级的锻造锤配方。

### 矿物作物产物

安装流体输入仓后，可以处理 CropsNH 矿物作物的收获物。例如铜纤维、锡芽和铁齿叶等产物有需要硫酸的 LV 锻造锤配方，可用于持续生产对应矿物。其他作物所需的流体和配方等级可能不同，应逐项查看 NEI。

这些常见配方用编程电路选择产物：配置 1 产出纯净粉碎矿石，配置 2 产出含杂粉。将作物收获物送入蒸汽输入总线，按 NEI 设置电路，并向普通流体输入仓供给足量配方流体。

蒸汽仍通过蒸汽仓输入，用于机器供能；酸液等配方原料由另装的流体输入仓接收。两种仓室都要保留，不能用输入仓代替蒸汽仓。并行加工时，作物原料和配方流体的需求量都会随并行数增加。

### 首次运行

1. 完成结构检查，确认蒸汽仓、蒸汽输入总线和蒸汽输出总线均已安装。
2. 给蒸汽仓接通蒸汽管道，确认蒸汽能够实际进入仓室。
3. 在输出总线中留出空间，投入少量原料，数量至少满足一份配方；有流体和电路要求的配方也要准备齐全。
4. 开机，观察产物去向和蒸汽仓储量。
5. 确认持续供汽后，再增加原料和并行数量。

## 供汽与产能

大型蒸汽锻造锤最多同时执行 8 份**同一种配方**，不代表能在一轮中处理 8 种不同物品。实际并行数量还受原料数量、输出空间和 GUI 中的并行上限设置影响。

例如，一份制板配方需要 3 个锭并产出 2 个板，8 并行就需要 24 个锭，一轮产出 16 个板。只放入 8 个锭不能跑满 8 并行。

普通结构的运行速度是单方块青铜蒸汽锻造锤的 125%，耗时约为其 80%；每并行的蒸汽消耗速率为其 62.5%。速度和蒸汽消耗速率一起计算后，处理同一份物品的总蒸汽量约为其 50%，但整台机器同时运行多个并行时，瞬时蒸汽消耗量仍会增加。

| 项目 | 普通结构 | 高压结构 |
| --- | --- | --- |
| 可加工配方等级 | LV 及以下 | LV 及以下 |
| 最大并行 | 8 | 8 |
| 运行速度，以普通结构为基准 | 1 倍 | 2 倍 |
| 同一配方、相同并行的蒸汽消耗速率 | 1 倍 | 2 倍 |
| 单份配方的总蒸汽消耗量 | 基准 | 约与普通结构相同 |

高压升级把速度和蒸汽消耗速率一起提高，主要增加吞吐量，不会再把单份物品的总蒸汽消耗量减半；具体耗时和蒸汽消耗量还会受到 tick 与整数取整影响。

蒸汽仓可缓存 64,000 L 蒸汽，但缓存只能暂时补足供给，不能代替锅炉持续产汽。规划锅炉和管道时，要按**运行时的蒸汽消耗速率**供给。

可通过 Waila 查看运行时蒸汽消耗速率，并观察蒸汽仓在连续加工时是否持续下降。若界面使用 L/t，正常 20 TPS 下乘以 20 即为 L/s；比较管道吞吐量时也要统一单位。供汽不足时，可以在 GUI 中降低并行上限，再扩充锅炉产能或改善管道。

> [!WARNING]
> 加工期间蒸汽不足会使当前加工中止，已经投入的原料不会返还。升级高压结构或提高并行上限前，先检查蒸汽产量和管道速率。

## 升级高压结构

</GameScene>

高压结构的尺寸、仓室位置和控制器不变，但要把镀铜砖块、青铜管道方块和铁块**全部换成表中的脱氧钢机械方块、钢管道方块和钢块**。只换外壳，或保留其中一个铁块，都不能通过等级检查。

升级前先停止加工和原料输入。完成替换后重新检查结构，确认机器显示为高压等级，再恢复供汽和生产。

高压是机器的结构等级，不是一种额外的蒸汽流体。它仍使用普通蒸汽，原有蒸汽仓和蒸汽总线可以继续使用；也不需要改装电力能源仓。升级后速度和蒸汽消耗速率翻倍，但最大并行仍是 8，配方等级上限仍是 LV。

## 自动化与物品分流

蒸汽输入总线和蒸汽输出总线各有 4 个物品槽。它们不会自动从相邻箱子取料或把产物推入箱子，单纯贴着箱子放置并不能完成自动化。

- **输入**：使用漏斗、GT 物品管道、传送带或物品导管等设备，将物品送入输入总线正面。
- **输出**：从输出总线正面用管道、导管或传送带主动抽取，再送往存储或下一台机器。
- **蒸汽**：用流体管道把锅炉输出送入蒸汽仓，物品总线不能接收蒸汽。
- **配方流体**：加工矿物作物等需要流体的配方时，另接流体管道向普通输入仓供给 NEI 要求的酸液等原料。
- **分流**：制板、合成长杆和矿物处理可分别设置原料过滤，避免不同原料占满四个输入槽；矿物产物按实际物品种类送往后续设备。

增加输入总线能扩大物品缓冲，增加输出总线能减少输出堵塞，但都不会提高 8 并行的上限。加装流体输入仓或总线时至少保留 35 个真正的外壳，也不能再加第二个蒸汽仓。

## 故障排查

| 现象 | 检查内容 |
| --- | --- |
| 结构不完整 | 是否按占地 5×5、高 7 格搭建；控制器是否在第二层且距底座最前端一格；上部两个管道方块和中部两个金属块是否放对位置 |
| 提示结构等级不匹配 | 外壳、管道方块和金属块是否全部属于同一等级；升级后是否还留有铁块或青铜部件 |
| 缺少蒸汽仓或总线 | 是否安装恰好一个蒸汽仓及至少各一个蒸汽输入、输出总线；是否误用普通电力机器的物品总线 |
| 加总线后结构失效 | 是否保留至少 35 个真正的外壳；是否把管道方块或金属块位置换成了总线 |
| 有原料却找不到配方 | 是否确实存在锻造锤配方；输入数量是否满足一份配方；所需流体、电路是否齐全；输出空间是否足够 |
| 矿物作物产物不能加工 | 是否安装普通流体输入仓并供给配方要求的酸液等流体；电路配置是否正确；配方是否在 LV 及以下 |
| 提示配方等级过高 | NEI 中的配方是否超过 LV；高压结构也不能处理 MV 及以上配方 |
| 蒸汽仓有汽但运行后停机 | 持续供汽是否跟得上；管道是否受限或分流；当前并行和高压等级是否超过锅炉能力 |
| 箱子贴着总线却不传物品 | 蒸汽总线不会自动拉取或推出物品，检查主动输送设备及其连接面、方向和过滤 |
| 实际加工数量不到 8 份 | 原料是否为同一种配方且数量足够；并行上限是否被调低；输出槽是否能容纳全部产物 |

更多通用结构检查与工具操作见[多方块机器](./multiblocks_index.md)。
