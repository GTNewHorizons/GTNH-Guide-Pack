# 蒸馏塔

<GameScene interactive={true} wrap="square" align="right" width="320" height="300">
  <ImportStructureLib controller="gregtech:gt.blockmachines:1126" />
</GameScene>

<ItemLink id="gregtech:gt.blockmachines:1126" showIcon="left" />（Distillation Tower，简称 DT，俗称“大蒸馏”）是 HV 阶段的多方块加工机器。它能把一种流体同时分离成 NEI 配方列出的全部馏分，是单方块蒸馏室的直接升级，常用于石油、木焦油、生物质及各种化工流体的处理。

蒸馏塔的高度取决于配方的流体产物数量。每一种流体产物占用一个独立输出层，因此搭建前应先查看目标配方，而不是直接照搬另一座蒸馏塔的高度。

| 项目 | 说明 |
| --- | --- |
| 解锁阶段 | HV；控制器配方需要 EV 电路板，通常要先建成超净间 |
| 结构尺寸 | 3×3×3–12，底层上方中空，顶层中央封顶 |
| 供电 | 普通能源仓，可安装多个；不支持多安能源仓和激光靶仓 |
| 超频 | 标准有损超频：每次功率变为 4 倍，耗时减半 |
| 加工加成 | 最大并行数为 1，没有额外速度或耗电加成 |
| 维护与污染 | 需要维护，不产生污染，无需消声仓 |

蒸馏塔是横截面固定为 3×3、高度可变的塔形结构。控制器位于正面底层中央，底层放置输入接口；从第二层开始，每一层都必须至少安装一个输出仓。中间各层的中心保持为空气，顶层中央用洁净不锈钢机械方块封顶。

设总高度为 $$h$$，则必须保留至少 $$7h-5$$ 个真正的洁净不锈钢机械方块。仓室和总线不计入这个数量。

| 部件 | 数量与位置 |
| --- | --- |
| <ItemLink id="gregtech:gt.blockmachines:1126" showIcon="left" /> | 1 个，正面底层中央 |
| <ItemLink id="gregtech:gt.blockcasings4:1" showIcon="left" /> | 至少 16–79 个 |
| 输入仓 | 至少 1 个，任意底层外壳位置 |
| 输入总线 | 可选，任意底层外壳位置；配方需要物品输入时安装 |
| 输出总线 | 可选，任意底层外壳位置；配方会产出物品时安装 |
| 输出仓 | 每个非底层至少 1 个，共至少 2–11 个 |
| 普通能源仓 | 至少 1 个，任意合适外壳位置 |
| 维护仓 | 1 个，任意合适外壳位置 |

最低的 3 层结构需要 2 个输出层和至少 16 个外壳。常见的四流体产物配方需要 5 层结构、4 个输出层和至少 30 个外壳；最高的 12 层结构可以容纳 11 种流体产物，需要至少 79 个外壳。

一层可以安装多个输出仓，但增加仓室不能突破最低外壳数量。通常每层一个输出仓最容易布线；额外输出仓只会为该层对应的同一种流体增加缓存或输出接口，不会让机器多处理一种产物。

使用 <ItemLink id="structurelib:item.structurelib.constructableTrigger" showIcon="left" /> 可以查看结构投影并辅助搭建。对空气右键打开信道设置，将 `height` 子信道设为 3–12 来选择投影的总高度，再对控制器使用投影仪。

## 能做什么

单方块蒸馏室通常通过编程电路选择一种目标馏分，其余成分不会一同产出。蒸馏塔执行独立的蒸馏塔配方，用同一批原料同时得到配方中的全部流体产物；这也是它提高原料利用率并简化复杂化工产线的主要原因。

常见用途包括：

- **石油分馏**：同时得到重燃油、轻燃油、石脑油和炼油气等馏分，为柴油、十六烷值提升柴油及石油裂化产线提供原料。
- **木材化工**：处理木焦油、木醋酸和木煤气，取得苯、甲苯、苯酚、甲醇等燃料或化工原料。
- **生物质处理**：从发酵生物质等流体中回收多种副产物。
- **化学品分离**：处理稀酸、裂化燃料及其他需要同时回收多种产物的流体。

具体输入、输出、编程电路、耗电和耗时以 NEI 的“蒸馏塔”配方为准。部分配方带有物品输入或物品副产物，不能只安装流体仓室。

## 塔高与分层输出

先数出 NEI 配方中的**流体产物**数量 $$n$$；物品产物不计入塔高。所需总高度为：

$$
h=\max(3,n+1)
$$

最低高度固定为 3，因此即使配方只有一种流体产物，也仍需搭建两个输出层。结构可以高于配方要求，多出的顶层输出仓会保持空置，但不能低于配方要求。

NEI 中流体产物的读取顺序为**从左到右、从下到上**。第一个流体产物进入第二层输出仓，第二个进入第三层，之后依次向上。例如一个有四种流体产物的配方会使用第二至第五层，因此至少需要一座 5 层蒸馏塔。

> [!WARNING]
> 输出仓不是按其中已有的流体或管道过滤自动分配的。接错层会把产物送入错误的储罐或管道，甚至造成流体混合和产线堵塞。每次更换配方后，都应重新对照 NEI 确认各层产物。

## 供电与产能

HV 是取得控制器的阶段，不代表蒸馏塔只能接受 HV 电力。机器的可用电压由所装普通能源仓决定；更换更高等级的能源仓后，可以处理更高电压配方并进行[超频](../tierskipping-overcloking-parallels/overclocking.md)。安装两个同等级普通能源仓也可以按照普通多方块规则进行[双仓升压](../tierskipping-overcloking-parallels/tierskipping.md)。

蒸馏塔不支持多安能源仓或激光靶仓，也没有并行能力。标准有损超频每次把功率提高到 4 倍、耗时缩短为一半；达到 1 tick 后仍可继续超频，但不会因此一次处理多份配方。

蒸馏塔“同时获得全部馏分”来自它自己的配方，并不是并行加成。评估吞吐量时，应直接查看 NEI 中蒸馏塔配方的输入量、持续时间和耗电，而不能用单方块蒸馏室的某一个输出配方直接推算。

> [!WARNING]
> 加工过程中断电会使当前配方失败并损失已经投入的原料。升级能源仓或进行双仓升压后，也要确认电缆、变压器和发电端能持续提供所需功率。

## 自动化与产物分流

每个输出层应连接独立的流体管线和储罐。蒸馏塔只有在所有相关产物都有输出空间时才会开始下一次加工，因此某一种低需求副产物积满，也会让整座塔停机。

| 方案 | 注意事项 |
| --- | --- |
| 普通输出仓 | 每层接到独立储罐；储罐容量应能吸收下游短暂停机造成的积压 |
| 输出仓（ME） | 每个输出层仍需单独安装；可用剪线钳右键仓室，使 ME 线缆能够从任意一面连接 |
| 溢出销毁 | 只在确定不需要保留该产物时启用；下游满载后无法输出的流体会被永久销毁 |
| 共用外壳或仓室 | 可以节省材料，但共用输出仓时必须保证两台机器在该层输出兼容，否则容易互相堵塞 |

若配方需要编程电路或其他物品输入，在底层安装输入总线；若配方带有粉尘等物品产物，则同时安装输出总线。自动化完成后，先投入一批原料，逐层核对实际产物和目标储罐，再开启持续输入。

## 故障排查

| 现象 | 检查内容 |
| --- | --- |
| 结构不完整 | 总高度是否为 3–12；中间层中心是否为空气；顶层中央是否封顶；每个非底层是否都有输出仓；真正的外壳是否达到 $$7h-5$$ 个 |
| 输出空间不足 | 塔高是否容纳全部流体产物；对应层输出仓、管道或储罐是否已满；带物品产物的配方是否安装了输出总线 |
| 原料和电力齐全但没有配方 | 输入流体、编程电路和其他物品是否与 NEI 一致；物品是否放入输入总线；能源仓电压是否达到配方要求 |
| 产物进入错误管线 | 重新按 NEI 从左到右、从下到上的顺序，对照第二层起由低到高的输出仓 |
| 加高后仍按旧高度成型 | 顶层中央的旧封顶是否已拆除；新增各层是否安装输出仓；完成后手动更新结构检查 |
| 运行后立即停机 | 检查供电功率、线损、能源缓存和维护状态，不要连续投入更多原料试机 |

更多通用操作见[多方块机器](./multiblocks-index.md)。IV 阶段可以进一步了解丹格特蒸馏厂，LuV 阶段则可使用巨型蒸馏塔扩大产能。
