# 真空冷冻机

<GameScene interactive={true} wrap="square" align="right" width="320" height="280">
  <ImportStructureLib controller="gregtech:gt.blockmachines:1002" />
</GameScene>

<ItemLink id="gregtech:gt.blockmachines:1002" showIcon="left" />（Vacuum Freezer，简称 VF，俗称“冰箱”）是 HV 阶段的多方块加工机器。它常与[工业高炉](../tiers/lv/electric-blast-furnace.md)配套使用，把高炉产出的热锭冷却成可继续加工的普通锭。

并非所有高炉产物都需要冷却。安排生产线前，先在 NEI 中查看产物的用途；如果产出的是普通锭，就不必送入冷冻机。

| 项目 | 说明 |
| --- | --- |
| 解锁阶段 | HV |
| 结构尺寸 | 3×3×3，中心一格为空气 |
| 供电 | 普通能源仓，不支持多安能源仓和激光靶仓 |
| 超频 | 标准有损超频：每次功率变为 4 倍，耗时减半 |
| 加工加成 | 没有额外的速度、耗电或并行加成 |
| 维护与污染 | 需要维护，不产生污染，无需消声仓 |

搭建一个中空的 3×3×3 外壳，将控制器放在正面第二层中央。内部唯一的一格必须保持为空气，不需要放置线圈、冰块或冷却液。

| 部件 | 数量与位置 |
| --- | --- |
| <ItemLink id="gregtech:gt.blockmachines:1002" showIcon="left" /> | 1 个，正面第二层中央 |
| <ItemLink id="gregtech:gt.blockcasings2:1" showIcon="left" /> | 至少 16 个，其余外壳位置可替换为下列仓室或总线 |
| 能源仓 | 至少 1 个，任意外壳位置 |
| 维护仓 | 1 个，任意外壳位置 |
| 输入总线或输入仓 | 至少有一种，任意外壳位置 |
| 输出总线或输出仓 | 至少有一种，任意外壳位置 |

冷却热锭时，使用输入总线和输出总线；处理流体时，则安装配方所需的输入仓和输出仓。两类接口可以同时安装，但必须保留至少 16 个真正的防冻机械方块，仓室和总线不计入这个数量。

一台仅用于冷却热锭、配备一个能源仓、一个维护仓及各一个输入和输出总线的机器，需要 **21 个防冻机械方块**。增加仓室或总线时，相应减少外壳数量即可。

使用 <ItemLink id="structurelib:item.structurelib.constructableTrigger" showIcon="left" /> 可以查看结构投影并辅助搭建。完成后进行结构检查，再用维护工具处理控制器显示的维护问题。

## 能做什么

真空冷冻机的用途不止冷却热锭，还包括部分气体液化、冷却单元恢复，以及等离子体冷却配方。不同配方需要的电压和输入输出形式不同，不能只凭物品名称判断能否加工。

- **热锭冷却**：把工业高炉的热锭转为对应普通锭，例如镍铬合金热锭。
- **流体冷却**：通过输入仓加入配方要求的气体或等离子体，并用输出仓接收产物。
- **冷却单元恢复**：只有存在相应冷冻配方的单元或部件才能处理，并非所有反应堆部件都能在这里修复。

机器外壳不消耗冷却液，但具体配方仍可能要求流体原料。以 NEI 列出的输入、输出和耗电量为准。

## 供电与产能

HV 是取得机器的阶段，不代表它只能使用 HV 电力。升级能源仓可以提高可用电压，并对符合条件的配方进行[超频](../tierskipping-overcloking-parallels/overclocking.md)。它也遵循普通多方块的[升压规则](../tierskipping-overcloking-parallels/tierskipping.md)。

冷冻机没有加热线圈，因此不会获得工业高炉的高温折扣或高温无损超频。标准有损超频每次将功率提高到 4 倍、时间缩短为一半，单次加工的总耗电量也随之增加。

扩建高炉生产线后，要检查冷冻机输入端是否持续积压热锭。高炉的并行数量、线圈加成和配方耗时都会影响实际产量，不能仅凭两台机器使用同级能源仓就认为吞吐量一定匹配。

> [!WARNING]
> 加工过程中断电会使当前配方失败并损失已经投入的原料。供电线路不仅要达到配方电压，还要能持续提供机器运行所需的功率。

## 热锭分流

高炉可能同时产出热锭和不需要冷却的物品。给冷冻机配置输入过滤，可以避免普通产物占满输入总线。

普通输入总线支持用螺丝刀右键切换配方过滤；不要按住 Shift，Shift 操作调整的是其他输入设置。开启后，该总线只接受所属机器配方表中认可的输入物品。配方过滤并不等同于“只收热锭”，因为冷冻机也能处理其他物品。

选择运输方式时，可以采用以下原则：

| 运输方式 | 分流要点 |
| --- | --- |
| GT 物品管道 | 给冷冻机设置有效输入过滤，并为其余产物保留另一条可达的输出路径；注意管道距离和限制性管道对路由的影响 |
| Ender IO 物品导管 | 配置插入过滤和目的地优先级，让冷冻机接收可冷却物品，其他产物进入存储 |
| AE2 | 可按具体热锭设置过滤；使用支持矿物词典过滤的设备时，`ingotHot*` 可用于匹配热锭 |

连接自动化后，分别放入一种热锭和一种普通产物检查去向。确认冷却后的锭也有稳定的输出路径，避免输出总线塞满导致停产。

## 故障排查

| 现象 | 检查内容 |
| --- | --- |
| 结构不完整 | 中心是否为空气；是否保留至少 16 个防冻机械方块；是否有能源仓、维护仓以及输入和输出接口 |
| 原料进不去 | 总线是否属于已成型的机器；配方过滤是否开启；运输设备的方向、过滤和优先级是否正确 |
| 有原料但没有可用配方 | 输入是否真的需要冷却；物品或流体是否符合配方；能源仓电压是否足够 |
| 输出空间不足 | 对应的输出总线或输出仓是否存在、已满，或无法容纳本次产物 |
| 开始运行后立即停机 | 检查供电功率、线损、能源缓存和维护状态，不要连续投入更多原料试机 |

更多通用操作见[多方块机器](./multiblocks-index.md)。后期需要提高冷却产能时，可以进一步了解凛冰冷冻机。
