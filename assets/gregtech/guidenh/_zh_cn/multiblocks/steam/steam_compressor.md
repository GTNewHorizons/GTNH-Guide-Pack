# 大型蒸汽压缩机

<GameScene interactive={true} wrap="square" align="right" width="320" height="280">
  <ImportStructureLib controller="gregtech:gt.blockmachines:31078" tier={1} />
</GameScene>

<ItemLink id="gregtech:gt.blockmachines:31078" showIcon="left" />（Steam Squasher）是蒸汽阶段的多方块压缩机，使用蒸汽批量压缩材料。它是单方块蒸汽压缩机的升级版本，最多同时执行 8 份相同配方，可用于制作材料块、压缩耐火黏土和生产空气单元。

机器有普通青铜结构和高压钢结构两个等级，使用同一个控制器。升级高压结构可以提高产能，但不会提高可加工配方的等级，也不能替代需要特殊压缩等级的机器。

| 项目 | 说明 |
| --- | --- |
| 解锁阶段 | 蒸汽；控制器配方需要活塞、铜金合金齿轮和框架等材料 |
| 结构尺寸 | 宽 3 格、前后长 7 格、高 3 格；控制器位于正面第二层中央 |
| 供能 | 恰好 1 个蒸汽仓，不使用能源仓 |
| 配方范围 | 普通压缩机配方，限 LV 及以下，即配方需求不超过 32 EU/t |
| 特殊限制 | 不能执行要求特殊压缩等级的配方；高压钢结构也不能解锁 |
| 并行 | 最多 8 份相同配方；高压结构不增加并行上限 |
| 加工加成 | 普通结构相对单方块青铜蒸汽压缩机有 125% 运行速度、62.5% 的每并行蒸汽消耗速率 |
| 升级与超频 | 高压结构使速度和蒸汽消耗速率翻倍；没有电压超频 |
| 维护与污染 | 不需要维护，不产生污染，也不需要消声仓 |

新版结构共有 30 个可放外壳或仓室的位置。安装三个必需接口后，剩下 27 个外壳；增加一个输入仓后剩下 26 个。继续增加仓室或总线时，至少保留 14 个真正的外壳。管道方块和金属块不能换成仓室或总线。

使用 <ItemLink id="structurelib:item.structurelib.constructableTrigger" showIcon="left" /> 可以查看结构投影并辅助搭建。投影仪的主信道等级 1 对应普通结构，等级 2 对应高压结构；辅助搭建后仍需安装仓室、检查结构。

## 机器用途

大型蒸汽压缩机使用压缩机配方表。查看 NEI 时，先确认物品有压缩配方，再检查配方等级、输入数量、产物和特殊要求。

| 用途 | 常见加工与注意事项 |
| --- | --- |
| 制作材料块 | 适用的金属通常可以用 9 个锭压成 1 个金属块；部分粉也有压块配方，具体材料和等级以 NEI 为准 |
| 制作建筑方块 | 将黏土球、红砖、地狱砖、萤石粉等压成对应方块；例如 4 个红砖压成 1 个红砖块 |
| 制作压缩耐火黏土 | 将耐火黏土粉压成压缩耐火黏土，供后续烧制使用；压缩机本身不会完成烧制 |
| 生产空气单元 | 将空单元压成空气单元，作为后续空气处理流程的原料 |
| 其他普通压缩配方 | 处理符合等级要求的合金板等材料；是否可加工以 NEI 的压缩配方为准 |

### 空气单元与后续取氧

普通压缩配方可以用 **1 个空单元生成 1 个空气单元**。空单元从蒸汽输入总线送入，空气单元从蒸汽输出总线取出；这个配方只需要蒸汽供能，不需要额外供水、向输入仓注入空气或安装特殊集气装置。

空气单元可用于后续取氧、取氮流程，但这台机器本身只生成空气单元，**不会直接产出氧气或氮气**。继续加工前，在 NEI 中查看空气单元及空气流体的用途，并按后续机器的配方准备流体、单元和输出接口。

自动化时，把空单元送入压缩机，空气单元送往后续机器；流程返回的空单元可以再送回输入端。规划时要给单元周转留出缓冲，避免所有空单元都滞留在其他机器中。

> [!NOTE]
> 蒸汽阶段可以取得这台机器，但它最高只能处理 LV 配方。高压钢结构提高的是机器结构等级，不能让它接受 MV 或更高等级配方，也不能执行要求特殊压缩等级的配方。

### 首次运行

1. 完成结构检查，确认蒸汽仓、蒸汽输入总线和蒸汽输出总线均已安装。
2. 给蒸汽仓接通蒸汽管道，确认蒸汽能够实际进入仓室。
3. 在 NEI 中确认配方和输入数量，在输出总线中留出空间。
4. 开机并投入少量原料，观察产物去向和蒸汽仓储量。
5. 确认持续供汽后，再增加原料和并行数量。

## 供汽与产能

大型蒸汽压缩机最多同时执行 8 份**同一种配方**，不代表能在一轮中处理 8 种不同物品。实际并行数量还受原料数量、输出空间和 GUI 中的并行上限设置影响。

例如，一个压块配方用 9 个锭生成 1 个金属块，那么 8 并行需要 72 个锭，一轮产出 8 个金属块。

普通结构的运行速度是单方块青铜蒸汽压缩机的 125%，耗时约为其 80%；每并行的蒸汽消耗速率为其 62.5%。速度和蒸汽消耗速率一起计算后，处理同一份物品的总蒸汽量约为其 50%，但整台机器同时运行多个并行时，瞬时蒸汽消耗量仍会增加。

| 项目 | 普通结构 | 高压结构 |
| --- | --- | --- |
| 可加工配方等级 | LV 及以下的普通压缩配方 | LV 及以下的普通压缩配方 |
| 最大并行 | 8 | 8 |
| 运行速度，以普通结构为基准 | 1 倍 | 2 倍 |
| 同一配方、相同并行的蒸汽消耗速率 | 1 倍 | 2 倍 |
| 单份配方的总蒸汽消耗量 | 基准 | 约与普通结构相同 |

高压升级把速度和蒸汽消耗速率一起提高，主要增加吞吐量，不会再把单份物品的总蒸汽消耗量减半；具体耗时和蒸汽消耗量还会受到 tick 与整数取整影响。

蒸汽仓可缓存 64,000 L 蒸汽，但缓存只能暂时补足供给，不能代替锅炉持续产汽。规划锅炉和管道时，要按**运行时的蒸汽消耗速率**供给。

可通过 Waila 查看运行时蒸汽消耗速率，并观察蒸汽仓在连续加工时是否持续下降。若界面使用 L/t，正常 20 TPS 下乘以 20 即为 L/s；比较管道吞吐量时也要统一单位。供汽不足时，可以在 GUI 中降低并行上限，再扩充锅炉产能或改善管道。

> [!WARNING]
> 加工期间蒸汽不足会使当前加工中止，已经投入的原料不会返还。升级高压结构或提高并行上限前，先检查蒸汽产量和管道速率。

</GameScene>

高压结构的尺寸、仓室位置和控制器不变，但要把镀铜砖块、青铜管道方块和铁块**全部换成表中的脱氧钢机械方块、钢管道方块和钢块**。

升级前先停止加工和原料输入。完成替换后重新检查结构，确认机器显示为高压等级，再恢复供汽和生产。

高压是机器的结构等级，它仍使用普通蒸汽，原有蒸汽仓和蒸汽总线可以继续使用；升级后速度和蒸汽消耗速率翻倍，最大并行仍是 8。

## 自动化与物品分流

蒸汽输入总线和蒸汽输出总线各有 4 个物品槽。它们不会自动从相邻箱子取料或把产物推入箱子，单纯贴着箱子放置并不能完成自动化。

- **输入**：使用漏斗、GT 物品管道、传送带或物品导管等设备，将物品送入输入总线正面。
- **输出**：从输出总线正面用管道、导管或传送带主动抽取，再送往存储或下一台机器。
- **蒸汽**：用流体管道把锅炉输出送入蒸汽仓；普通输入仓不能代替蒸汽仓供能。
- **配方流体**：只有 NEI 配方要求流体输入时，才额外安装普通输入仓并供应对应流体；制作空气单元无需这个接口。
- **分流**：按材料块、压缩耐火黏土和空气单元等产物设置过滤，避免空气单元进入材料存储、需要烧制的中间产物滞留在输出端。

压块配方经常一次消耗多个物品。规划输入缓冲时，按“每份配方数量 × 目标并行”备料；尽量不要让多种零散材料占满输入槽，导致每种材料都凑不齐一份配方。

增加输入总线能扩大物品缓冲，增加输出总线能减少输出堵塞，但都不会提高并行上限。扩展时至少保留 14 个真正的外壳，也不能再加第二个蒸汽仓。

## 故障排查

| 现象 | 检查内容 |
| --- | --- |
| 新版结构不完整 | 是否按宽 3 格、前后长 7 格、高 3 格搭建；控制器是否在正面第二层中央；是否正确放置 10 个管道方块和 6 个金属块 |
| 提示结构等级不匹配 | 外壳、管道方块和金属块是否全部属于同一等级；是否只替换了部分青铜部件或保留了铁块 |
| 缺少蒸汽仓或总线 | 是否安装恰好一个蒸汽仓及至少各一个蒸汽输入、输出总线；是否误用普通电力机器的物品总线 |
| 加仓室后结构失效 | 是否保留至少 14 个真正的外壳；是否把管道方块或金属块位置换成了仓室或总线 |
| 有原料却找不到配方 | 是否确实存在压缩配方；输入数量是否满足一份配方；是否有压缩等级要求；输出空间是否足够 |
| 提示配方等级过高 | NEI 中的配方是否超过 LV；高压结构也不能处理 MV 及以上配方 |
| 空单元没有变成氧气单元 | 压缩机生成的是空气单元；氧气、氮气需要通过后续机器加工取得 |
| 蒸汽仓有汽但运行后停机 | 持续供汽是否跟得上；管道是否受限或分流；当前并行和高压等级是否超过锅炉能力 |
| 箱子贴着总线却不传物品 | 蒸汽总线不会自动拉取或推出物品，检查主动输送设备及其连接面、方向和过滤 |
| 实际加工数量不到 8 份 | 是否有足够原料执行 8 份相同配方；并行上限是否被调低；输出槽是否能容纳全部产物 |

更多通用结构检查与工具操作见[多方块机器](../multiblocks_index.md)。
