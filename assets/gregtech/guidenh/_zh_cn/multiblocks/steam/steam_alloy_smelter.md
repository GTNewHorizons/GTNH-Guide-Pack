# 大型蒸汽合金炉

<GameScene interactive={true} wrap="square" align="right" width="320" height="280">
  <ImportStructureLib controller="gregtech:gt.blockmachines:31086" tier={1} />
</GameScene>

<ItemLink id="gregtech:gt.blockmachines:31086" showIcon="left" />（Steam Fuser）是蒸汽阶段的多方块合金炉，使用蒸汽批量制作合金和处理适用的模具成型配方。它是单方块蒸汽合金炉的升级版本，最多同时执行 8 份相同配方，可用于生产青铜、红色合金、黄铜等材料。

机器有普通青铜结构和高压钢结构两个等级，使用同一个控制器。升级高压结构可以提高产能，但不会提高可加工配方的等级。机器使用蒸汽供能，不需要放入煤炭等燃料，也不需要线圈或设置炉温。

| 项目 | 说明 |
| --- | --- |
| 解锁阶段 | 蒸汽；控制器配方需要铜金合金框架、青铜流体管道和高炉等材料 |
| 结构尺寸 | 宽 3 格、前后长 4 格、高 3 格；控制器位于正面第二层中央 |
| 供能 | 恰好 1 个蒸汽仓，不使用能源仓 |
| 配方范围 | 合金炉配方，限 LV 及以下，即配方需求不超过 32 EU/t |
| 物品接口 | 至少各 1 个蒸汽输入总线和蒸汽输出总线；普通电力机器的物品总线不能代替 |
| 流体接口 | 仅需蒸汽仓供能，不接受普通输入仓或输出仓 |
| 并行 | 最多 8 份相同配方；高压结构不增加并行上限 |
| 加工耗时 | 普通结构约为 NEI 标称耗时的 1.6 倍，高压结构约为 0.8 倍 |
| 升级与超频 | 高压结构使速度和蒸汽消耗速率翻倍；没有电压超频 |
| 维护与污染 | 不需要维护，不产生污染，也不需要消声仓 |

### 结构材料

下面按一个蒸汽仓、一个输入总线和一个输出总线的基础配置备料。普通结构使用镀铜砖块和青铜管道方块，高压结构使用对应的钢制部件；**同一台机器的外壳与管道方块必须属于同一等级**。

| 部件 | 普通结构 | 高压结构 | 数量与位置 |
| --- | --- | --- | --- |
| 外壳 | <ItemLink id="gregtech:gt.blockcasings:10" showIcon="left" /> | <ItemLink id="gregtech:gt.blockcasings2:0" showIcon="left" /> | 基础配置 26 个；可替换为下列仓室或总线，但至少保留 25 个真正的外壳 |
| 管道方块 | <ItemLink id="gregtech:gt.blockcasings2:12" showIcon="left" /> | <ItemLink id="gregtech:gt.blockcasings2:13" showIcon="left" /> | 2 个，第二层中央，沿控制器后方连续放置 |
| 玻璃 | <ItemLink id="minecraft:glass" showIcon="left" /> 等受支持的玻璃 | 可继续使用原玻璃 | 4 个，两个管道方块的左、右各放 1 个 |
| 控制器 | <ItemLink id="gregtech:gt.blockmachines:31086" showIcon="left" /> | 同一控制器 | 1 个，正面第二层中央 |
| 蒸汽仓 | <ItemLink id="gregtech:gt.blockmachines:31040" showIcon="left" /> | 同一仓室 | 恰好 1 个，替换一个外壳位置 |
| 输入总线 | <ItemLink id="gregtech:gt.blockmachines:31046" showIcon="left" /> | 同一总线 | 至少 1 个，替换外壳位置 |
| 输出总线 | <ItemLink id="gregtech:gt.blockmachines:31047" showIcon="left" /> | 同一总线 | 至少 1 个，替换外壳位置 |

结构共有 29 个可放外壳或仓室的位置。安装三个必需接口后剩下 26 个外壳，最多还能把一个外壳换成额外的蒸汽输入或输出总线；再增加接口会使外壳少于 25 个。玻璃和管道方块不能换成仓室或总线。

底层和顶层都是完整的 3×4 平面。第二层从前往后依次是“外壳、控制器、外壳”“玻璃、管道、玻璃”“玻璃、管道、玻璃”和一排三个外壳；仓室与总线放在外壳位置。

> [!NOTE]
> 普通玻璃可以构成这台机器，不必为了投影中显示的硼玻璃额外准备硼。玻璃不参与青铜或钢结构的等级匹配，升级高压结构时也无需换玻璃。

使用 <ItemLink id="structurelib:item.structurelib.constructableTrigger" showIcon="left" /> 可以查看结构投影并辅助搭建。投影仪的主信道等级 1 对应普通结构，等级 2 对应高压结构；辅助搭建后仍需安装仓室、检查结构。

## 机器用途

大型蒸汽合金炉使用**合金炉配方表**，英文 NEI 中显示为 **Alloy Smelter**。查看 NEI 时，确认配方属于合金炉，再核对原料形态、比例、配方等级和所需模具。

| 用途 | 常见加工与注意事项 |
| --- | --- |
| 常用合金 | 铜与锡制成青铜，铜与锌制成黄铜；使用 NEI 中对应的锭、粉等输入形式 |
| 电路与导线材料 | 铜与红石制成红色合金；银与蓝石制成蓝色合金 |
| 其他低压合金 | 金与银制成琥珀金，铅与锑制成电池合金，锡与锑制成焊锡合金；具体比例以 NEI 为准 |
| 橡胶加工 | 生橡胶粉与硫粉制成橡胶条，可供后续橡胶制品使用 |
| 模具成型 | 按适用配方，用对应模具制作金属粒、锭、齿轮或物品外壳等；模具种类和材料用量以 NEI 为准 |

合金配方直接生成对应合金锭，不需要先混成合金粉再烧制。但它并不接受所有熔炉或工业高炉配方；普通烧制可使用[蒸汽壁炉](./steam_hearth.md)，要求高炉温度或更高电压的冶炼应使用对应机器。

> [!NOTE]
> 蒸汽阶段可以取得这台机器，但它最高只能处理 LV 配方。高压钢结构提高的是机器结构等级，不能让它接受 MV 或更高等级配方。不要只凭材料名称判断能否加工，应查看具体配方的 EU/t。

### 原料比例与青铜生产

当前常见青铜配方每份使用 **3 个铜锭与 1 个锡锭，生成 4 个青铜锭**。也有使用对应粉末或混合锭、粉的配方，输入形态应按 NEI 选择；不要把小撮粉、小堆粉或金属粒直接按锭的数量投入。

不是所有合金都统一比例。例如红色合金使用铜与红石，焊锡合金使用锡与锑；更换材料时重新查看 NEI，不要沿用青铜的配比。

### 模具与材料成型

部分合金炉配方需要模具。把 NEI 指定的模具和材料一起放入蒸汽输入总线；配方中标为不消耗的模具会保留，可重复使用，也不需要为 8 并行准备 8 个模具。

合金炉模具与挤压机模具不是同一种物品。即使图标或目标形状相似，也应使用对应合金炉配方指定的模具。模具只改变符合该配方的材料形状，不会让机器接受更高电压的配方。

固定生产一种零件时，给模具保留一个输入槽，并让输送设备只补充消耗的原料。更换模具前先停止供料、等待当前加工完成，再清理余料，避免执行其他成型配方。

### 首次运行

1. 完成结构检查，确认蒸汽仓、蒸汽输入总线和蒸汽输出总线均已安装。
2. 给蒸汽仓接通蒸汽管道，确认蒸汽能够实际进入仓室。
3. 在 NEI 中核对原料形态、比例和配方等级；需要模具时放入对应模具。
4. 给产物留出输出空间，投入少量原料开机。
5. 观察原料配比、蒸汽储量和产物去向，确认持续供汽后再增加并行数量。

## 供汽与产能

大型蒸汽合金炉最多同时执行 8 份**同一种配方**，不代表能在一轮中执行 8 种不同合金配方，也不代表一轮只消耗 8 个物品。实际并行数量还受各原料数量、输出空间和 GUI 中的并行上限设置影响。

普通结构的加工耗时约为 NEI 配方标称耗时的 1.6 倍，高压结构约为 0.8 倍。例如，标称耗时 10 秒的青铜配方，普通结构约需 16 秒，高压结构约需 8 秒；8 并行时这一轮产出 32 个青铜锭，耗时不会再除以 8。

| 项目 | 普通结构 | 高压结构 |
| --- | --- | --- |
| 可加工配方等级 | LV 及以下 | LV 及以下 |
| 最大并行 | 8 | 8 |
| 加工耗时，相对 NEI 标称耗时 | 约 1.6 倍 | 约 0.8 倍 |
| 同一配方、相同并行的蒸汽消耗速率 | 1 倍 | 2 倍 |
| 单份配方的总蒸汽消耗量 | 基准 | 约与普通结构相同 |
| 单份配方的原料与产物 | 按 NEI 配方计算 | 与普通结构相同 |

普通结构相对单方块青铜蒸汽合金炉有 125% 的运行速度、62.5% 的每并行蒸汽消耗速率，处理同一份配方的总蒸汽量约为其 50%。但同时运行多个并行时，整台机器的蒸汽消耗速率仍会增加，不能按一台单方块机器的用汽量配置满并行生产。

高压升级把速度和蒸汽消耗速率一起提高，主要增加吞吐量，单份配方的总蒸汽消耗量约与普通结构相同；具体耗时和蒸汽消耗量还会受到 tick 与整数取整影响。

蒸汽仓可缓存 64,000 L 蒸汽，但缓存只能暂时补足供给，不能代替锅炉持续产汽。规划锅炉和管道时，要按**运行时的蒸汽消耗速率**供给；多台机器共用一条管道时，还要考虑分流后的实际流量。

可通过 Waila 查看运行时蒸汽消耗速率，并观察蒸汽仓在连续加工时是否持续下降。若界面使用 L/t，正常 20 TPS 下乘以 20 即为 L/s；比较管道吞吐量时也要统一单位。供汽不足时，可以在 GUI 中降低并行上限，再扩充锅炉产能或改善管道。

> [!WARNING]
> 加工期间蒸汽不足会使当前加工中止，已经投入的原料不会返还。升级高压结构或提高并行上限前，先检查蒸汽产量和管道速率。

## 升级高压结构

</GameScene>

高压结构的尺寸、仓室位置和控制器不变，但要把镀铜砖块与青铜管道方块**全部换成表中的脱氧钢机械方块和钢管道方块**。原有玻璃、蒸汽仓和蒸汽总线可以继续使用。

升级前先停止加工和原料输入。完成替换后重新检查结构，确认机器显示为高压等级，再恢复供汽、供料和生产。

高压是机器的结构等级，它仍使用普通蒸汽；升级后速度和蒸汽消耗速率翻倍，最大并行仍是 8，也不会解锁 MV 及以上配方。

## 自动化与物品分流

蒸汽输入总线和蒸汽输出总线各有 4 个物品槽。它们不会自动从相邻箱子取料或把产物推入箱子，单纯贴着箱子放置并不能完成自动化。

- **输入**：使用漏斗、GT 物品管道、传送带或物品导管等设备，将原料送入输入总线正面；为每种原料保留槽位，并按配方比例持续补充。
- **模具**：需要模具的配方保留对应模具，不要让抽取设备把模具一起取走；输入过滤也要避免装入错误模具。
- **输出**：从输出总线正面用管道、导管或传送带主动抽取，再送往合金存储、制板或其他后续加工。
- **蒸汽**：用流体管道把锅炉输出送入蒸汽仓；普通输入仓不能代替蒸汽仓供能。
- **更换配方**：先停止供料并等待当前加工完成，再处理余料和模具；避免不同配方的零散原料占满总线或混合成非预期合金。

基础配置最多还能增加一个蒸汽输入或输出总线。选择扩大原料缓冲还是产物缓冲时，先看实际堵塞位置；增加总线不会提高并行上限，并且必须至少保留 25 个真正的外壳，不能再加第二个蒸汽仓。

> [!WARNING]
> 需要完整收集产物时，把 GUI 中的溢出销毁设为“不销毁”。输出总线堵塞或存储已满时，先处理输出，避免允许销毁导致合金和成型零件丢失。

## 故障排查

| 现象 | 检查内容 |
| --- | --- |
| 结构不完整 | 是否按宽 3 格、前后长 4 格、高 3 格搭建；控制器是否在正面第二层中央；是否正确放置 2 个管道方块和 4 个玻璃 |
| 提示结构等级不匹配 | 外壳和管道方块是否全部属于同一等级；是否只替换了部分青铜部件 |
| 玻璃位置不通过检查 | 是否用了普通玻璃等受支持的玻璃方块；是否误放玻璃板或其他不受支持的装饰方块 |
| 缺少蒸汽仓或总线 | 是否安装恰好一个蒸汽仓及至少各一个蒸汽输入、输出总线；是否误用普通电力机器的物品总线 |
| 加接口后结构失效 | 是否保留至少 25 个真正的外壳；是否把玻璃或管道方块换成了仓室；是否误加普通输入仓或输出仓 |
| 原料齐全却找不到配方 | 是否查看合金炉配方；原料形态与比例是否符合 NEI；模具是否正确；输出空间是否足够 |
| 有铜却不能继续生产青铜 | 锡是否足够，或铜是否占满输入槽使锡无法进入；是否错误投入了铜金属粒、小撮铜粉等其他形态 |
| 模具放进去却不成型 | 是否误用挤压机模具；NEI 是否存在该材料的对应成型配方；材料用量与配方等级是否满足 |
| 提示配方等级过高 | NEI 中的配方是否超过 LV；高压结构也不能处理 MV 及以上配方 |
| 蒸汽仓有汽但运行后停机 | 持续供汽是否跟得上；管道是否受限或分流；当前并行和高压等级是否超过锅炉能力 |
| 箱子贴着总线却不传物品 | 蒸汽总线不会自动拉取或推出物品，检查主动输送设备及其连接面、方向和过滤 |
| 实际加工数量不到 8 份 | 每一种原料是否足够执行 8 份相同配方；并行上限是否被调低；输出总线是否能容纳全部产物 |

更多通用结构检查与工具操作见[多方块机器](../multiblocks_index.md)。
