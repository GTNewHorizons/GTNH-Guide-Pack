# 大型蒸汽离心机

<GameScene interactive={true} wrap="square" align="right" width="320" height="280">
  <ImportStructureLib controller="gregtech:gt.blockmachines:31080" tier={1} />
</GameScene>

<ItemLink id="gregtech:gt.blockmachines:31080" showIcon="left" />（Steam Separator）是蒸汽阶段的多方块离心机，使用蒸汽批量分离材料，最多同时执行 8 份相同配方。它可以提纯矿粉、从黏性树脂中取得生橡胶粉，以及收集离心配方中的物品和流体产物。

机器有普通青铜结构和高压钢结构两个等级，使用同一个控制器。它让玩家在蒸汽阶段就能执行适用的离心配方；升级高压结构可以提高产能，但不会提高可加工配方的等级。

| 项目 | 说明 |
| --- | --- |
| 解锁阶段 | 蒸汽；控制器配方需要铸铁板、青铜齿轮和铜金合金框架等材料 |
| 结构尺寸 | 占地 5×5，高 5 格；控制器位于正面第二层中央 |
| 供能 | 恰好 1 个蒸汽仓，不使用能源仓 |
| 配方范围 | 离心机配方，限 LV 及以下，即配方需求不超过 32 EU/t |
| 输入与输出 | 使用蒸汽输入总线输入物品；蒸汽输出总线输出物品，普通输出仓输出流体；不接受普通输入仓 |
| 并行 | 最多 8 份相同配方；高压结构不增加并行上限 |
| 加工耗时 | 普通结构约为 NEI 标称耗时的 1.6 倍，高压结构约为 0.8 倍 |
| 升级与超频 | 高压结构使速度和蒸汽消耗速率翻倍；没有电压超频 |
| 维护与污染 | 不需要维护，不产生污染，也不需要消声仓 |

| 输入总线 | <ItemLink id="gregtech:gt.blockmachines:31046" showIcon="left" /> | 同一总线 | 至少 1 个，替换外壳位置 |
| 输出总线 | <ItemLink id="gregtech:gt.blockmachines:31047" showIcon="left" /> | 同一总线 | 按物品产物需要安装，替换外壳位置 |
| 输出仓 | 例如 <ItemLink id="gregtech:gt.blockmachines:60" showIcon="left" /> | 同一仓室 | 按流体产物需要安装，替换外壳位置 |

结构共有 69 个可放外壳或仓室的位置。安装上方四个接口后剩下 65 个外壳；如果只执行纯物品产物的配方，不安装输出仓，则需要 66 个外壳。增加总线或输出仓时再相应减少外壳数量，但必须至少保留 60 个真正的外壳。齿轮箱、管道方块和燃烧室不能换成仓室或总线。

层数从底座向上计算。各层外壳的形状不同，按交互结构或投影搭建，空位无需填实。蒸汽输出总线和普通输出仓至少要安装一种；如果配方同时产生物品和流体，就应同时安装两种输出接口。

这里的燃烧室是结构方块，不需要投入燃料或单独供水。机器运行所需的蒸汽由外部锅炉生产，再通过蒸汽仓送入。

使用 <ItemLink id="structurelib:item.structurelib.constructableTrigger" showIcon="left" /> 可以查看结构投影并辅助搭建。投影仪的主信道等级 1 对应普通结构，等级 2 对应高压结构；辅助搭建后仍需安装仓室、检查结构。

## 机器用途

大型蒸汽离心机使用离心机配方表。查看 NEI 时，先确认配方属于**离心机**，再检查等级、输入形式、编程电路和全部产物。

| 用途 | 常见加工与注意事项 |
| --- | --- |
| 矿粉提纯 | 将适用的含杂粉、纯净粉等变成普通粉，并取得对应副产物；不同矿物的数量和产物形式以 NEI 为准 |
| 黏性树脂处理 | 取得生橡胶粉、概率产出的植物球和胶水；需要同时处理物品与流体输出 |
| 原木离心 | 适用的原木配方可生成甲烷，橡胶原木还有概率物品产物；注意 NEI 要求的编程电路配置 |
| 矿物与材料分离 | 处理适用的地狱岩粉、末地石粉等离心配方，分别收集多个物品或流体产物 |
| 单元类配方 | 仅处理存在物品输入形式的离心配方；有些配方还需要额外的空单元，不能只放入一个装满的单元就认为原料齐全 |

### 黏性树脂与橡胶

当前黏性树脂离心配方每份消耗 **1 个黏性树脂**，产出 **3 个生橡胶粉和 100 L 胶水**，并有 **10% 概率产出 1 个植物球**。

把黏性树脂送入蒸汽输入总线，用蒸汽输出总线收集生橡胶粉和植物球，用普通输出仓收集胶水。胶水是配方产物，**不要给机器安装输入仓来接收胶水**。

8 并行时，一轮需要 8 个黏性树脂，产出 24 个生橡胶粉和 800 L 胶水；植物球仍按概率产出，不保证一轮有 8 个。持续运行前，给两类物品留出空间，并用流体管道及时抽走胶水。

### 流体输入限制

这台机器支持流体**输出**，但不接受普通流体输入仓。NEI 中要求流体输入的配方，即使等级不超过 LV，也不能通过增加普通输入仓来执行。蒸汽仓只用于供能，不能作为空气、酸液等配方流体的输入接口。

例如，NEI 中直接以空气流体为输入的离心配方，应使用能接收流体输入的离心机。装有流体的单元只有在对应配方明确把它列为**物品输入**时，才能按该配方送入蒸汽输入总线。

> [!NOTE]
> 蒸汽阶段可以取得这台机器，但它最高只能处理 LV 配方。换成高压钢结构不会使其接受 MV 或更高等级配方，也不会解除流体输入限制。

### 首次运行

1. 完成结构检查，确认蒸汽仓、蒸汽输入总线和所需输出接口均已安装。
2. 给蒸汽仓接通蒸汽管道，确认蒸汽能够实际进入仓室。
3. 在 NEI 中确认配方等级、全部输入和编程电路配置，并检查是否要求流体输入。
4. 给全部物品和流体产物预留空间，投入少量原料开机，观察输出和蒸汽仓储量。
5. 确认持续供汽和产物收集后，再增加原料和并行数量。

## 供汽与产能

大型蒸汽离心机最多同时执行 8 份**同一种配方**，不代表能在一轮中处理 8 种不同物品。实际并行数量还受原料数量、输出空间和 GUI 中的并行上限设置影响。

普通结构的加工耗时约为 NEI 配方标称耗时的 1.6 倍，高压结构约为 0.8 倍。例如，标称耗时 15 秒的黏性树脂配方，普通结构约需 24 秒，高压结构约需 12 秒。并行提高一轮加工的份数，不会把这一轮的耗时再除以并行数量。

| 项目 | 普通结构 | 高压结构 |
| --- | --- | --- |
| 可加工配方等级 | LV 及以下 | LV 及以下 |
| 最大并行 | 8 | 8 |
| 加工耗时，相对 NEI 标称耗时 | 约 1.6 倍 | 约 0.8 倍 |
| 同一配方、相同并行的蒸汽消耗速率 | 1 倍 | 2 倍 |
| 单份配方的总蒸汽消耗量 | 基准 | 约与普通结构相同 |

高压升级把速度和蒸汽消耗速率一起提高，主要增加吞吐量，单份物品的总蒸汽消耗量约与普通结构相同；具体耗时和蒸汽消耗量还会受到 tick 与整数取整影响。

蒸汽仓可缓存 64,000 L 蒸汽，但缓存只能暂时补足供给，不能代替锅炉持续产汽。规划锅炉和管道时，要按**运行时的蒸汽消耗速率**供给。提高并行数后，物品输入、物品输出和流体输出也都要跟上。

可通过 Waila 查看运行时蒸汽消耗速率，并观察蒸汽仓在连续加工时是否持续下降。若界面使用 L/t，正常 20 TPS 下乘以 20 即为 L/s；比较管道吞吐量时也要统一单位。供汽不足时，可以在 GUI 中降低并行上限，再扩充锅炉产能或改善管道。

> [!WARNING]
> 加工期间蒸汽不足会使当前加工中止，已经投入的原料不会返还。升级高压结构或提高并行上限前，先检查蒸汽产量和管道速率。

</GameScene>

高压结构的尺寸、仓室位置和控制器不变，但要把镀铜砖块、青铜齿轮箱、青铜管道方块和青铜燃烧室**全部换成表中的脱氧钢机械方块、钢齿轮箱、钢管道方块和钢燃烧室**。

升级前先停止加工和原料输入。完成替换后重新检查结构，确认机器显示为高压等级，再恢复供汽和生产。

高压是机器的结构等级，它仍使用普通蒸汽，原有蒸汽仓、蒸汽总线和输出仓可以继续使用；升级后速度和蒸汽消耗速率翻倍，最大并行仍是 8。

## 自动化与产物分流

蒸汽输入总线和蒸汽输出总线各有 4 个物品槽。它们不会自动从相邻箱子取料或把产物推入箱子，单纯贴着箱子放置并不能完成自动化。

- **输入**：使用漏斗、GT 物品管道、传送带或物品导管等设备，将物品送入输入总线正面；同时准备配方需要的空单元和编程电路配置。
- **物品输出**：从输出总线正面用管道、导管或传送带主动抽取，分别送往主产物存储、副产物存储或下一台机器。
- **流体输出**：从普通输出仓抽走胶水、甲烷等产物，按流体种类配置存储和过滤；多种流体产物要准备足够的输出仓。
- **蒸汽**：用独立的供汽管线连接蒸汽仓，避免把流体产物管线接到蒸汽仓。
- **矿物分流**：根据普通粉、含杂粉、纯净粉和细小副产物设置过滤，避免已经完成离心的产物再次占用输入缓冲。

离心配方经常同时产出多个不同物品，一个只有 4 槽的输出总线可能装不下全部产物。增加输出总线可以扩大物品输出空间，但不会提高并行上限。扩展仓室或总线时至少保留 60 个真正的外壳，也不能再加第二个蒸汽仓。

> [!WARNING]
> 需要完整回收副产物时，把 GUI 中的溢出销毁设为“不销毁”，并为全部物品和流体提供输出空间。允许销毁流体后，未安装输出仓或输出仓堵塞时，胶水等产物可能直接被丢弃。

## 故障排查

| 现象 | 检查内容 |
| --- | --- |
| 结构不完整 | 是否按占地 5×5、高 5 格搭建；控制器是否在正面第二层中央；齿轮箱、管道方块和燃烧室是否按投影放置 |
| 提示结构等级不匹配 | 外壳、齿轮箱、管道方块和燃烧室是否全部属于同一等级；是否只替换了部分青铜部件 |
| 缺少蒸汽仓或输入总线 | 是否安装恰好一个蒸汽仓及至少一个蒸汽输入总线；是否误用普通电力机器的物品总线 |
| 缺少输出接口 | 是否至少安装蒸汽输出总线或普通输出仓之一；是否按配方产物同时安装所需的两类接口 |
| 加仓室后结构失效 | 是否保留至少 60 个真正的外壳；是否把齿轮箱、管道方块或燃烧室换成了仓室 |
| 有原料却找不到配方 | 是否确实存在离心机配方；是否误看成热力离心机配方；输入数量、空单元和电路配置是否齐全 |
| LV 配方有流体输入却不能加工 | 本机不接受普通输入仓；改用能接收对应输入形式的离心机 |
| 提示配方等级过高 | NEI 中的配方是否超过 LV；高压结构也不能处理 MV 及以上配方 |
| 有物品产物却没有胶水等流体 | 是否安装普通输出仓；是否锁定了错误流体；是否开启了流体溢出销毁；产物是否已被管道抽走 |
| 没有植物球或其他概率副产物 | 是否为概率输出；少量配方未出现副产物可能是正常情况，也要检查输出空间和溢出销毁设置 |
| 提示输出空间不足 | 是否给全部物品和流体留出空间；一个 4 槽输出总线是否不足；输出仓是否堵塞或锁定了错误流体 |
| 蒸汽仓有汽但运行后停机 | 持续供汽是否跟得上；管道是否受限或分流；当前并行和高压等级是否超过锅炉能力 |
| 箱子贴着总线却不传物品 | 蒸汽总线不会自动拉取或推出物品，检查主动输送设备及其连接面、方向和过滤 |

更多通用结构检查与工具操作见[多方块机器](../multiblocks_index.md)。
