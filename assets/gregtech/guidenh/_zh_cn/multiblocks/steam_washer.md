# 大型蒸汽洗矿厂

<GameScene interactive={true} wrap="square" align="right" width="320" height="280">
  <ImportStructureLib controller="gregtech:gt.blockmachines:31082" tier={1} />
</GameScene>

<ItemLink id="gregtech:gt.blockmachines:31082" showIcon="left" />（Steam Purifier）是蒸汽阶段的多方块洗矿机器，使用蒸汽和水批量处理矿物，最多同时执行 8 份相同配方。它有**洗矿厂**和**简易洗矿厂**两种模式，可以在收集副产物与快速洗涤之间选择。

机器有普通青铜结构和高压钢结构两个等级，使用同一个控制器。它让玩家在蒸汽阶段就能清洗粉碎矿石；简易模式还可以快速洗涤适用的含杂粉和纯净粉。升级高压结构可以提高产能，但不会提高可加工配方的等级。

| 项目 | 说明 |
| --- | --- |
| 解锁阶段 | 蒸汽；控制器配方需要铸铁板、锡转子和铜金合金框架等材料 |
| 结构尺寸 | 宽 9 格、深 5 格、高 6 格；控制器位于小立方体部分的正面第二层中央 |
| 供能 | 恰好 1 个蒸汽仓，不使用能源仓 |
| 配方范围 | 洗矿厂或简易洗矿厂配方，限 LV 及以下，即配方需求不超过 32 EU/t |
| 输入与输出 | 蒸汽输入总线输入物品，输入仓输入配方用水，蒸汽输出总线输出物品 |
| 运行模式 | 默认洗矿厂模式；可用螺丝刀或 GUI 切换到简易洗矿厂模式 |
| 并行 | 最多 8 份相同配方；高压结构不增加并行上限 |
| 加工耗时 | 普通结构约为 NEI 标称耗时的 1.6 倍，高压结构约为 0.8 倍 |
| 升级与超频 | 高压结构使速度和蒸汽消耗速率翻倍；没有电压超频 |
| 维护与污染 | 不需要维护，不产生污染，也不需要消声仓 |

### 结构材料

下面按一个蒸汽仓、一个输入总线、一个输出总线和一个输入仓的配置备料。普通结构使用青铜部件，高压结构使用对应钢制部件；**同一台机器的外壳、齿轮箱和管道方块必须属于同一等级**。

| 部件 | 普通结构 | 高压结构 | 数量与位置 |
| --- | --- | --- | --- |

| 齿轮箱 | <ItemLink id="gregtech:gt.blockcasings2:2" showIcon="left" /> | <ItemLink id="gregtech:gt.blockcasings2:3" showIcon="left" /> | 8 个，位于水槽底座，围绕中央外壳排列 |
| 管道方块 | <ItemLink id="gregtech:gt.blockcasings2:12" showIcon="left" /> | <ItemLink id="gregtech:gt.blockcasings2:13" showIcon="left" /> | 12 个，构成槽内管道及上方连接管道 |
| 玻璃 | 例如 <ItemLink id="minecraft:glass" showIcon="left" /> | 可继续使用原来的玻璃 | 24 个，构成水槽两层侧壁；使用投影接受的玻璃方块 |
| 控制器 | <ItemLink id="gregtech:gt.blockmachines:31082" showIcon="left" /> | 同一控制器 | 1 个，小立方体部分的正面第二层中央 |
| 蒸汽仓 | <ItemLink id="gregtech:gt.blockmachines:31040" showIcon="left" /> | 同一仓室 | 恰好 1 个，替换一个外壳位置 |
| 输入总线 | <ItemLink id="gregtech:gt.blockmachines:31046" showIcon="left" /> | 同一总线 | 至少 1 个，替换外壳位置 |
| 输出总线 | <ItemLink id="gregtech:gt.blockmachines:31047" showIcon="left" /> | 同一总线 | 至少 1 个，替换外壳位置 |
| 输入仓 | 例如 <ItemLink id="gregtech:gt.blockmachines:51" showIcon="left" /> | 同一仓室 | 至少 1 个，替换外壳位置，用于输入水 |

结构共有 63 个可放外壳或仓室的位置。安装上方四个接口后剩下 59 个外壳；增加输入仓或总线时再相应减少外壳数量，但必须至少保留 55 个真正的外壳。齿轮箱、管道方块和玻璃不能换成仓室或总线。

层数从底座向上计算。结构由小立方体、旁边的玻璃水槽和上方管道组成，控制器不在整个 9 格宽结构的中央。按交互结构或投影搭建，主机只能水平朝向，不能绕主机正面旋转结构；投影中的空位无需填实。

使用 <ItemLink id="structurelib:item.structurelib.constructableTrigger" showIcon="left" /> 可以查看结构投影并辅助搭建。投影仪的主信道等级 1 对应普通结构，等级 2 对应高压结构；辅助搭建后仍需安装仓室、检查结构。

### 水槽与配方用水

这台机器的蒸汽、水槽中的水和配方用水分别有不同用途：

| 位置 | 用途 |
| --- | --- |
| 蒸汽仓 | 接收外部锅炉生产的蒸汽，为机器供能 |
| 输入仓 | 接收普通水或对应配方要求的蒸馏水；每份配方从这里扣除用水 |
| 结构水槽 | 第二层中央管道周围的 8 格水位；可以手动放置水源，也可以由机器取水填充 |

水槽中间的管道方块要保留，其周围的 8 个水位允许先留空。机器检查水槽时，会从输入仓中每次取 **1,000 L 普通水**，填成一个水源方块；全部水位为空时，首次填充最多额外消耗 **8,000 L 普通水**。这部分用水与当轮配方用水分开计算，开机前应准备足够缓存。

也可以用水桶手动填满这 8 个水位。**放在水槽中的水不能代替输入仓里的配方用水**；水槽填好后，仍要持续向输入仓供水。水槽不会随每份配方消耗，但取走水源后，机器再次检查时会尝试补充。结构检查接受水源或空气，流动水不能代替水源。

普通洗矿模式存在蒸馏水配方，但自动填充空水槽只使用**普通水**。准备使用蒸馏水洗矿时，可以先用水桶填好水槽，或额外安装一个普通水输入仓供填充使用。

## 机器用途

### 两种洗矿模式

使用 <ItemLink id="gregtech:gt.metatool.01:22" showIcon="left" /><kbd>右键</kbd>控制器，或点击 GUI 中的模式按钮，可以在洗矿厂和简易洗矿厂模式之间切换。

| 项目 | 洗矿厂模式 | 简易洗矿厂模式 |
| --- | --- | --- |
| 配方表 | NEI 中的洗矿厂配方 | NEI 中的简易洗矿厂配方 |
| 常见输入 | 粉碎矿石等适用的矿物中间产物 | 适用的粉碎矿石、含杂粉和纯净粉 |
| 常见主产物 | 粉碎矿石变成纯净粉碎矿石 | 粉碎矿石变成纯净粉碎矿石；含杂粉、纯净粉变成普通粉 |
| 副产物 | 收集配方列出的石粉和矿物副产物，其中部分按概率产出 | 只得到提纯后的主产物，没有洗矿或离心副产物 |
| 常见单份用水 | 普通水 1,000 L，或蒸馏水 200 L；以 NEI 对应配方为准 | 普通水 100 L |
| 常见 NEI 标称耗时 | 普通水配方 25 秒，蒸馏水配方 15 秒；具体配方可能不同 | 5 tick，即正常 20 TPS 下的 0.25 秒 |

需要矿物副产物时，选择普通洗矿模式，并给所有产物留出输出空间；只需要快速取得主产物时，可以选择简易模式。简易模式既快又省水，适合大量处理已经确定不需要副产物的材料。

含杂粉和纯净粉也可以先查看[大型蒸汽离心机](./steam_centrifuge.md)的配方：离心通常能在取得普通粉的同时回收对应副产物，简易洗矿则会省去这些副产物。根据具体矿物的 NEI 配方选择处理路线。

> [!WARNING]
> 简易模式不会产生普通洗矿或离心路线中的副产物。已经简易洗涤的物品，不能靠切回普通模式补回这些产物；处理需要副产物的矿物前，先确认当前模式。

### 矿物处理路线

清洗粉碎矿石的产物通常是**纯净粉碎矿石**，并非可直接用于所有合成的普通粉。后续应根据 NEI 选择研磨、离心或其他处理步骤，按物品名称和形态分流。

- **保留副产物**：把粉碎矿石送入洗矿厂模式，分别收集纯净粉碎矿石、石粉和矿物副产物，再安排后续加工。
- **快速清洗**：把适用的粉碎矿石送入简易模式，只收集纯净粉碎矿石。
- **快速提纯矿粉**：把适用的含杂粉或纯净粉送入简易模式，取得普通粉；如果需要对应的离心副产物，改走离心路线。

并非所有材料、所有矿物形态都有简易洗矿配方。纯净粉碎矿石与纯净粉是不同物品，不要仅凭名称中带有“纯净”就认为能够继续放入简易模式加工。

### 首次运行

1. 完成结构检查，确认蒸汽仓、蒸汽输入总线、蒸汽输出总线和输入仓均已安装。
2. 用独立管线分别给蒸汽仓供汽、给输入仓供水；如果水槽留空，先储备足够的普通水供自动填充。
3. 选择所需模式，在 NEI 中确认对应配方表、原料形态、用水种类及全部产物。
4. 给全部产物预留空间，先投入少量原料，观察水槽、输出、蒸汽仓和输入仓储量。
5. 确认持续供汽、供水和产物收集后，再增加原料和并行数量。

> [!NOTE]
> 当前版本首次启动或定期检查水槽时，可能短暂显示“没有水”，完成检查后下一次配方检测会重新尝试。先确认输入仓的水和槽内水源，再稍等观察；持续不能运行时，按下方故障排查检查。

## 供汽、供水与产能

大型蒸汽洗矿厂最多同时执行 8 份**同一种配方**，不代表能在一轮中处理 8 种不同矿物。实际并行数量还受原料数量、配方用水、输出空间和 GUI 中的并行上限设置影响。

普通结构的加工耗时约为 NEI 配方标称耗时的 1.6 倍，高压结构约为 0.8 倍。常见普通水洗矿配方标称耗时 25 秒，普通结构约需 40 秒，高压结构约需 20 秒。简易洗矿配方标称耗时 5 tick，普通结构约需 8 tick，高压结构约需 4 tick；实际连续吞吐还受配方检查、供料和输出影响。

| 项目 | 普通结构 | 高压结构 |
| --- | --- | --- |
| 可加工配方等级 | LV 及以下 | LV 及以下 |
| 最大并行 | 8 | 8 |
| 加工耗时，相对 NEI 标称耗时 | 约 1.6 倍 | 约 0.8 倍 |
| 同一配方、相同并行的蒸汽消耗速率 | 1 倍 | 2 倍 |
| 单份配方的总蒸汽消耗量 | 基准 | 约与普通结构相同 |
| 单份配方用水 | 按 NEI 配方消耗 | 与普通结构相同 |

并行提高一轮加工的份数，不会把这一轮的耗时再除以并行数量。常见 8 并行普通水洗矿一轮需要 **8,000 L 水**；蒸馏水配方一轮需要 **1,600 L 蒸馏水**；简易洗矿一轮需要 **800 L 水**。开机时若还要自动填充水槽，需另外准备填槽用的普通水。

简易模式每份配方用水较少，但加工很快，输入仓缓存和供水管道仍可能成为瓶颈。高压升级不减少单份配方用水，随着加工速度翻倍，连续生产所需的供水速率也会提高。

蒸汽仓可缓存 64,000 L 蒸汽，但缓存只能暂时补足供给，不能代替锅炉持续产汽。规划锅炉和管道时，要按**运行时的蒸汽消耗速率**供给；同时观察输入仓的水量是否跟得上。

可通过 Waila 查看运行时蒸汽消耗速率，并观察蒸汽仓在连续加工时是否持续下降。若界面使用 L/t，正常 20 TPS 下乘以 20 即为 L/s；比较管道吞吐量时也要统一单位。供汽或供水不足时，可以先在 GUI 中降低并行上限，再扩充锅炉或改善管道。

> [!WARNING]
> 加工期间蒸汽不足会使当前加工中止，已经投入的原料不会返还。升级高压结构或提高并行上限前，先检查蒸汽产量和管道速率。

## 升级高压结构

</GameScene>

高压结构的尺寸、仓室位置和控制器不变，但要把镀铜砖块、青铜齿轮箱和青铜管道方块**全部换成表中的脱氧钢机械方块、钢齿轮箱和钢管道方块**。玻璃不参与青铜与钢结构的等级匹配，可以继续使用原来的普通玻璃。

升级前先停止加工和原料输入。完成替换后重新检查结构，确认机器显示为高压等级，再恢复供汽、供水和生产。

高压是机器的结构等级，它仍使用普通蒸汽，原有蒸汽仓、蒸汽总线和输入仓可以继续使用；升级后速度和蒸汽消耗速率翻倍，最大并行仍是 8，也不会解锁 MV 及以上配方。

## 自动化与产物分流

蒸汽输入总线和蒸汽输出总线各有 4 个物品槽。它们不会自动从相邻箱子取料或把产物推入箱子，单纯贴着箱子放置并不能完成自动化。

- **输入**：使用漏斗、GT 物品管道、传送带或物品导管等设备，将矿物送入输入总线正面，并按粉碎矿石、含杂粉和纯净粉等形态过滤。
- **输出**：从输出总线正面用管道、导管或传送带主动抽取，分别送往主产物存储、副产物存储或下一台机器。
- **供汽与供水**：使用独立管线，蒸汽接蒸汽仓，水接输入仓；蒸馏水洗矿与普通水填槽需要分别安排储量和接口。
- **副产物**：普通模式要同时处理石粉和矿物副产物，不要只过滤主产物而让其他物品堆在总线里。
- **模式切换**：先停止原料输入，等待当前加工完成，核对模式与剩余物料后再恢复输送，避免切换后按另一条路线处理后续原料。

洗矿配方可能同时产出多个不同物品，一个只有 4 槽的输出总线可能装不下连续加工的全部产物。增加输出总线可以扩大输出空间，但不会提高并行上限。扩展仓室或总线时至少保留 55 个真正的外壳，也不能再加第二个蒸汽仓。

> [!WARNING]
> 需要完整回收副产物时，把 GUI 中的溢出销毁设为“不销毁”，并为所有产物提供输出空间。允许销毁物品后，输出堵塞时主产物或副产物可能被丢弃。

## 故障排查

| 现象 | 检查内容 |
| --- | --- |
| 结构不完整 | 是否按宽 9、深 5、高 6 格搭建；控制器是否在小立方体正面第二层中央；管道、齿轮箱、玻璃和水位是否按投影放置 |
| 提示结构等级不匹配 | 外壳、齿轮箱和管道方块是否全部属于同一等级；是否只替换了部分青铜部件 |
| 缺少仓室或总线 | 是否安装恰好一个蒸汽仓及至少一个蒸汽输入总线、蒸汽输出总线和输入仓；是否误用普通电力机器的物品总线 |
| 加仓室后结构失效 | 是否保留至少 55 个真正的外壳；是否把玻璃、齿轮箱或管道方块换成了仓室 |
| 水槽不自动填充 | 输入仓中是否有普通水；每个空水位需要 1,000 L；只有蒸馏水不会自动填槽；也可以用水桶放置水源 |
| 水槽有水却不能加工 | 输入仓中是否还有对应配方要求的水；槽内水不能代替配方用水；是否只有流动水而没有水源 |
| 短暂显示“没有水” | 可能正在首次或定期检查水槽，确认水量后等待下一次配方检测；持续不能运行时再检查模式、配方和结构 |
| 有矿物却找不到配方 | 是否选对洗矿厂或简易洗矿厂模式；是否存在对应配方；是否把纯净粉碎矿石与纯净粉混淆；输入水种类是否正确 |
| 提示配方等级过高 | NEI 中的配方是否超过 LV；高压结构也不能处理 MV 及以上配方 |
| 没有石粉或矿物副产物 | 是否使用简易模式；副产物是否按概率产出；是否开启物品溢出销毁；是否已被管道抽走 |
| 提示输出空间不足 | 是否为全部产物留出槽位；一个 4 槽输出总线是否不足；石粉或副产物是否没有被抽走 |
| 只能低并行运行或频繁等待 | 原料、输入仓水量和输出空间是否足够；供水是否跟得上简易模式；GUI 并行上限是否被调低 |
| 蒸汽仓有汽但运行后停机 | 持续供汽是否跟得上；管道是否受限或分流；当前并行和高压等级是否超过锅炉能力 |
| 箱子贴着总线却不传物品 | 蒸汽总线不会自动拉取或推出物品，检查主动输送设备及其连接面、方向和过滤 |

更多通用结构检查与工具操作见[多方块机器](./multiblocks_index.md)。
