# 大型蒸汽研磨机

<GameScene interactive={true} wrap="square" align="right" width="320" height="280">
  <ImportStructureLib controller="gregtech:gt.blockmachines:31041" tier={1} />
</GameScene>

<ItemLink id="gregtech:gt.blockmachines:31041" showIcon="left" />（Steam Grinder）是蒸汽阶段的多方块研磨机，使用蒸汽批量粉碎矿石和材料。它是单方块蒸汽研磨机的升级版本，最多同时执行 8 份相同配方，可用于早期矿物处理线。

机器有普通青铜结构和高压钢结构两个等级，使用同一个控制器。升级高压结构可以提高产能，但不会提高可加工配方的等级，也不会增加矿物副产物。

| 项目 | 说明 |
| --- | --- |
| 解锁阶段 | 蒸汽；控制器配方需要钻石、活塞和铜金合金框架等材料 |
| 结构尺寸 | 占地 3×3，高 4 格；控制器位于正面第二层中央 |
| 供能 | 恰好 1 个蒸汽仓，不使用能源仓 |
| 配方范围 | 研磨机配方，限 LV 及以下，即配方需求不超过 32 EU/t |
| 产物限制 | 只产出配方列表中的第一个物品；高压结构也不增加输出种类 |
| 并行 | 最多 8 份相同配方；不按配方功率增加并行上限 |
| 加工加成 | 普通结构相对单方块青铜蒸汽研磨机有 125% 运行速度、62.5% 的每并行蒸汽消耗速率 |
| 升级与超频 | 高压结构使速度和蒸汽消耗速率翻倍；没有电压超频 |
| 维护与污染 | 不需要维护，不产生污染，也不需要消声仓 |

### 逐层放置

层数从底座向上计算。先确定控制器朝向，再照交互结构或投影逐层搭建。

| 层数 | 放置内容 |
| --- | --- |
| 第一层 | 铺满 3×3 底座，共 9 个外壳位置 |
| 第二层 | 四个角放框架，正面中央放控制器，左、右、后方中央各放一个外壳位置 |
| 第三层 | 四个角继续放框架，四边中央各放一个外壳位置 |
| 第四层 | 正中央放齿轮箱，四边中央各放一个外壳位置；四个角不用补方块 |

第二层和第三层中央的空位不用补成实心外壳。把蒸汽仓和蒸汽专用输入、输出总线放在合适的外壳位置，方便管道连接；普通电力机器的物品总线不能代替蒸汽专用总线。

使用 <ItemLink id="structurelib:item.structurelib.constructableTrigger" showIcon="left" /> 可以查看结构投影并辅助搭建。投影仪的主信道等级 1 对应普通结构，等级 2 对应高压结构；辅助搭建后仍需安装仓室、检查结构。

> [!NOTE]
> 本页按 2.9.0 的新版结构编写。当前 RC-2 仍兼容旧的 3×3×3 中空结构，但投影仪展示和辅助搭建使用新版结构。旧版页面中按配方功率计算并行的说明不适用于当前版本，机器的并行上限固定为 8。

## 机器用途与产物

大型蒸汽研磨机使用研磨机配方表。查看 NEI 时，先确认物品有研磨配方，再检查配方等级、输入数量和**第一个物品产物**。

| 用途 | 常见加工与注意事项 |
| --- | --- |
| 矿石初步粉碎 | 将适用的矿石变成粉碎矿石；许多常见矿石可在这一步增加主产物数量，具体产量以 NEI 为准 |
| 粉碎矿物中间产物 | 适用的粉碎矿石可变成含杂粉，离心矿石可变成矿粉；机器不会自动完成后续洗矿、离心或冶炼 |
| 材料研磨 | 将有对应配方的锭、宝石等材料研磨为粉，供合金和其他加工使用 |
| 物品回收 | 处理有研磨回收配方的部件或物品；加工前检查产物，避免把仍要使用的物品送入机器 |

### 为什么没有副产物

机器只生成研磨配方列表中的**第一个物品输出**。NEI 中第二个及后续位置的物品，即使标有产出概率，也不会由这台机器产出。这是机器本身的限制，不是输出总线少了槽位。

例如，一个研磨配方显示主矿物、矿物副产物和石粉三个输出时，大型蒸汽研磨机只处理第一个输出的数量与概率。增加输出总线、提高并行数或升级高压结构，都不会解锁其余输出。

需要研磨步骤的矿物副产物时，可以查看 <ItemLink id="gregtech:gt.blockmachines:303" showIcon="left" /> 等具有更多输出的机器。矿物处理线中的洗矿、离心也有各自的产物，应分别根据对应机器和 NEI 配方规划。

> [!NOTE]
> 蒸汽阶段可以取得这台机器，但它最高只能处理 LV 配方。换成高压钢结构不会使其接受 MV 或更高等级配方，也不会改变只生成第一个物品输出的限制。

### 首次运行

1. 完成结构检查，确认蒸汽仓、蒸汽输入总线和蒸汽输出总线均已安装。
2. 给蒸汽仓接通蒸汽管道，确认蒸汽能够实际进入仓室。
3. 在 NEI 中确认配方等级和第一个物品产物，在输出总线中留出空间。
4. 开机并投入少量原料，观察产物去向和蒸汽仓储量。
5. 确认持续供汽后，再增加原料和并行数量。

## 供汽与产能

大型蒸汽研磨机最多同时执行 8 份**同一种配方**，不代表能在一轮中处理 8 种不同物品。实际并行数量还受原料数量、输出空间和 GUI 中的并行上限设置影响。低功率配方也不会把并行上限提高到 8 以上。

普通结构的运行速度是单方块青铜蒸汽研磨机的 125%，耗时约为其 80%；每并行的蒸汽消耗速率为其 62.5%。速度和蒸汽消耗速率一起计算后，处理同一份物品的总蒸汽量约为其 50%，但整台机器同时运行多个并行时，瞬时蒸汽消耗量仍会增加。

| 项目 | 普通结构 | 高压结构 |
| --- | --- | --- |
| 可加工配方等级 | LV 及以下 | LV 及以下 |
| 最大并行 | 8 | 8 |
| 物品输出种类 | 仅配方的第一个物品输出 | 仅配方的第一个物品输出 |
| 运行速度，以普通结构为基准 | 1 倍 | 2 倍 |
| 同一配方、相同并行的蒸汽消耗速率 | 1 倍 | 2 倍 |
| 单份配方的总蒸汽消耗量 | 基准 | 约与普通结构相同 |

高压升级把速度和蒸汽消耗速率一起提高，主要增加吞吐量，不会再把单份物品的总蒸汽消耗量减半；具体耗时和蒸汽消耗量还会受到 tick 与整数取整影响。

蒸汽仓可缓存 64,000 L 蒸汽，但缓存只能暂时补足供给，不能代替锅炉持续产汽。规划锅炉和管道时，要按**运行时的蒸汽消耗速率**供给。

可通过 Waila 查看运行时蒸汽消耗速率，并观察蒸汽仓在连续加工时是否持续下降。若界面使用 L/t，正常 20 TPS 下乘以 20 即为 L/s；比较管道吞吐量时也要统一单位。供汽不足时，可以在 GUI 中降低并行上限，再扩充锅炉产能或改善管道。

> [!WARNING]
> 加工期间蒸汽不足会使当前加工中止，已经投入的原料不会返还。升级高压结构或提高并行上限前，先检查蒸汽产量和管道速率。

## 升级高压结构

  <ImportStructureLib controller="gregtech:gt.blockmachines:31041" tier={2} />
</GameScene>

高压结构的尺寸、仓室位置和控制器不变，但要把镀铜砖块、青铜框架和青铜齿轮箱**全部换成表中的脱氧钢机械方块、钢框架和钢齿轮箱**。只换外壳，或保留部分青铜框架、青铜齿轮箱，都不能通过新版结构的等级检查。

升级前先停止加工和原料输入。完成替换后重新检查结构，确认机器显示为高压等级，再恢复供汽和生产。

高压是机器的结构等级，不是一种额外的蒸汽流体。它仍使用普通蒸汽，原有蒸汽仓和蒸汽总线可以继续使用；也不需要改装电力能源仓。升级后速度和蒸汽消耗速率翻倍，最大并行仍是 8。

## 自动化与物品分流

蒸汽输入总线和蒸汽输出总线各有 4 个物品槽。它们不会自动从相邻箱子取料或把产物推入箱子，单纯贴着箱子放置并不能完成自动化。

- **输入**：使用漏斗、GT 物品管道、传送带或物品导管等设备，将物品送入输入总线正面。
- **输出**：从输出总线正面用管道、导管或传送带主动抽取，再送往存储或下一台机器。
- **蒸汽**：用流体管道把锅炉输出送入蒸汽仓，物品总线不能接收蒸汽。
- **分流**：按矿石、粉碎矿石、含杂粉和其他材料设置过滤，避免中间产物进入错误的处理步骤。

同一台研磨机可能用于矿物处理线的多个步骤。如果把原矿和刚产出的粉碎矿石都送回同一输入总线，要检查过滤和优先级，避免某一步长期占满输入槽。需要连续处理多步时，可分别配置机器，并检查整条线共用的蒸汽供给。

增加输入总线能扩大物品缓冲，增加输出总线能减少输出堵塞，但都不会提高并行上限或解锁副产物。扩展时至少保留 14 个真正的外壳，也不能再加第二个蒸汽仓。

## 故障排查

| 现象 | 检查内容 |
| --- | --- |
| 新版结构不完整 | 是否按占地 3×3、高 4 格搭建；控制器是否在正面第二层中央；第二、第三层的 8 个框架和顶层齿轮箱是否放对位置 |
| 提示结构等级不匹配 | 外壳、框架和齿轮箱是否全部属于同一等级；是否只替换了部分青铜部件 |
| 缺少蒸汽仓或总线 | 是否安装恰好一个蒸汽仓及至少各一个蒸汽输入、输出总线；是否误用普通电力机器的物品总线 |
| 加总线后结构失效 | 是否保留至少 14 个真正的外壳；是否把框架或齿轮箱位置换成了总线 |
| 有原料却找不到配方 | 是否确实存在研磨配方；输入数量是否满足一份配方；输出空间是否足够 |
| 提示配方等级过高 | NEI 中的配方是否超过 LV；高压结构也不能处理 MV 及以上配方 |
| NEI 显示副产物但机器不产出 | 机器只生成第一个物品输出；其余输出不会因增加输出总线或升级高压结构而解锁 |
| 蒸汽仓有汽但运行后停机 | 持续供汽是否跟得上；管道是否受限或分流；当前并行和高压等级是否超过锅炉能力 |
| 箱子贴着总线却不传物品 | 蒸汽总线不会自动拉取或推出物品，检查主动输送设备及其连接面、方向和过滤 |
| 实际加工数量不到 8 份 | 原料是否为同一种配方且数量足够；并行上限是否被调低；输出槽是否能容纳全部产物 |

更多通用结构检查与工具操作见[多方块机器](./multiblocks_index.md)。
