# 大型蒸汽搅拌机

<GameScene interactive={true} wrap="square" align="right" width="320" height="280">
  <ImportStructureLib controller="gregtech:gt.blockmachines:31084" tier={1} />
</GameScene>

<ItemLink id="gregtech:gt.blockmachines:31084" showIcon="left" />（Steam Blender），是蒸汽阶段的多方块搅拌机，使用蒸汽批量搅拌材料，最多同时执行 8 份相同配方。它可以制作青铜粉、黄铜粉、耐火黏土粉等材料，也可以直接输入和输出流体，制作盐水等适用的搅拌产物。

机器有普通青铜结构和高压钢结构两个等级，使用同一个控制器。它让玩家在蒸汽阶段就能执行适用的搅拌机配方；升级高压结构可以提高产能，但不会提高可加工配方的等级。

| 项目 | 说明 |
| --- | --- |
| 解锁阶段 | 蒸汽；控制器配方需要铜金合金环、铜金合金转子和铜金合金框架等材料 |
| 结构尺寸 | 占地 5×5，高 4 格；控制器位于正面第二层中央 |
| 供能 | 恰好 1 个蒸汽仓，不使用能源仓 |
| 配方范围 | 无流体单元的搅拌机配方，限 LV 及以下，即配方需求不超过 32 EU/t |
| 物品接口 | 蒸汽输入总线和蒸汽输出总线；普通电力机器的物品总线不能代替 |
| 流体接口 | 普通输入仓输入配方流体，普通输出仓收集流体产物；与供能用的蒸汽仓分开 |
| 并行 | 最多 8 份相同配方；高压结构不增加并行上限 |
| 加工耗时 | 普通结构约为 NEI 标称耗时的 1.6 倍，高压结构约为 0.8 倍 |
| 升级与超频 | 高压结构使速度和蒸汽消耗速率翻倍；没有电压超频 |
| 维护与污染 | 不需要维护，不产生污染，也不需要消声仓 |

| 输入仓 | 例如 <ItemLink id="gregtech:gt.blockmachines:51" showIcon="left" /> | 同一仓室 | 按流体输入需要安装，替换外壳位置 |

新版结构共有 40 个可放外壳或仓室的位置。安装上方五个接口后剩下 35 个外壳；只混合粉末时，安装蒸汽仓、蒸汽输入总线和蒸汽输出总线即可，此时需要 37 个外壳。增加总线或仓室时再相应减少外壳数量，但必须至少保留 25 个真正的外壳。框架、齿轮箱和管道方块不能换成仓室或总线。

结构检查要求至少一种配方输入接口，以及至少一种输出接口，不要求物品与流体接口全部安装。实际运行时，要按配方的全部输入和产物配置接口；需要多种流体时，单个普通输入仓不能同时装下它们，应准备相应数量的输入仓。

使用 <ItemLink id="structurelib:item.structurelib.constructableTrigger" showIcon="left" /> 可以查看结构投影并辅助搭建。投影仪的主信道等级 1 对应普通结构，等级 2 对应高压结构；辅助搭建后仍需安装仓室、检查结构。

## 机器用途

### 配方表与流体单元

大型蒸汽搅拌机使用**多方块搅拌机配方表**，英文 NEI 中显示为 **Multiblock Mixer**。含有流体单元的单方块搅拌机配方，通常在这张配方表中改为直接输入、输出对应流体，物品和编程电路等物品条件仍需满足。

查看 NEI 时，确认当前配方属于这张配方表，再检查物品数量、流体种类与数量、编程电路编号、配方等级及全部产物。

| 用途 | 常见加工与注意事项 |
| --- | --- |
| 合金粉混合 | 铜粉与锡粉制成青铜粉，铜粉与锌粉制成黄铜粉；注意原料比例和电路编号，产物是粉而不是锭 |
| 耐火黏土粉 | 砖粉与黏土粉混合；可用于后续耐火材料配方 |

> [!NOTE]
> 蒸汽阶段可以取得这台机器，但它最高只能处理 LV 配方。合金粉、化工混合物等材料是否能加工，应看对应配方的 EU/t；高压钢结构不会使其接受 MV 或更高等级配方。

### 编程电路与青铜粉

许多搅拌配方要求 <ItemLink id="gregtech:gt.integrated_circuit:1" showIcon="left" />。可以在蒸汽输入总线 GUI 的电路槽中设置 NEI 要求的编号。

当前常见青铜粉配方每份需要 **3 个铜粉、1 个锡粉和编号 1 的编程电路**，产出 **4 个青铜粉**。把铜粉和锡粉送入蒸汽输入总线，设置电路编号 1，用蒸汽输出总线收集青铜粉。

8 并行时，一轮需要 24 个铜粉和 8 个锡粉，产出 32 个青铜粉。持续输入时保持 3:1 的配比，避免铜粉占满所有槽位而使锡粉无法进入。

青铜粉还要按 NEI 安排后续冶炼；其他合金粉可能需要工业高炉等机器。

### 首次运行

1. 完成结构检查，确认蒸汽仓及所需的物品、流体接口均已安装。
2. 给蒸汽仓接通蒸汽管道，并分别给普通输入仓供应配方流体。
3. 在 NEI 中确认无单元配方、全部输入数量、编程电路编号和配方等级。
4. 设置电路，给全部物品和流体产物预留空间，投入少量原料开机。
5. 观察蒸汽缓存、原料配比和输出；确认持续供料与收集后，再增加并行数量。

## 供汽与产能

大型蒸汽搅拌机最多同时执行 8 份**同一种配方**，不代表能在一轮中执行 8 种不同配方，也不代表一轮只消耗 8 个物品。实际并行数量还受原料配比、物品和流体储量、输出空间及 GUI 中的并行上限设置影响。

普通结构的加工耗时约为 NEI 配方标称耗时的 1.6 倍，高压结构约为 0.8 倍。例如，标称耗时 2 秒的青铜粉配方，普通结构约需 3.2 秒，高压结构约需 1.6 秒。并行提高一轮加工的份数，不会把这一轮的耗时再除以并行数量。

| 项目 | 普通结构 | 高压结构 |
| --- | --- | --- |
| 可加工配方等级 | LV 及以下 | LV 及以下 |
| 最大并行 | 8 | 8 |
| 加工耗时，相对 NEI 标称耗时 | 约 1.6 倍 | 约 0.8 倍 |
| 同一配方、相同并行的蒸汽消耗速率 | 1 倍 | 2 倍 |
| 单份配方的总蒸汽消耗量 | 基准 | 约与普通结构相同 |
| 单份配方的原料与产物 | 按 NEI 配方计算 | 与普通结构相同 |

高压升级把速度和蒸汽消耗速率一起提高，主要增加吞吐量，单份配方的总蒸汽消耗量约与普通结构相同；具体耗时和蒸汽消耗量还会受到 tick 与整数取整影响。连续生产时，物品和配方流体的输入、输出速率也要随加工速度一起提高。

蒸汽仓可缓存 64,000 L 蒸汽，但缓存只能暂时补足供给，不能代替锅炉持续产汽。规划锅炉和管道时，要按**运行时的蒸汽消耗速率**供给，并给配方流体使用独立管线。

可通过 Waila 查看运行时蒸汽消耗速率，并观察蒸汽仓在连续加工时是否持续下降。若界面使用 L/t，正常 20 TPS 下乘以 20 即为 L/s；比较管道吞吐量时也要统一单位。供汽不足时，可以在 GUI 中降低并行上限，再扩充锅炉产能或改善管道。

> [!WARNING]
> 加工期间蒸汽不足会使当前加工中止，已经投入的物品和配方流体不会返还。升级高压结构或提高并行上限前，先检查蒸汽产量和管道速率。

## 升级高压结构

  <ImportStructureLib controller="gregtech:gt.blockmachines:31084" tier={2} />
</GameScene>

高压结构的尺寸、仓室位置和控制器不变，但要把镀铜砖块、青铜框架、青铜齿轮箱和青铜管道方块**全部换成表中的脱氧钢机械方块、钢框架、钢齿轮箱和钢管道方块**。

升级前先停止加工和原料输入。完成替换后重新检查结构，确认机器显示为高压等级，再恢复供汽、供料和生产。

高压是机器的结构等级，它仍使用普通蒸汽，原有蒸汽仓、蒸汽总线和普通输入、输出仓可以继续使用；升级后速度和蒸汽消耗速率翻倍，最大并行仍是 8，也不会解锁 MV 及以上配方。

## 自动化与产物分流

蒸汽输入总线和蒸汽输出总线各有 4 个物品槽，输入总线另有电路槽。它们不会自动从相邻箱子取料或把产物推入箱子，单纯贴着箱子放置并不能完成自动化。

- **物品输入**：使用漏斗、GT 物品管道、传送带或物品导管等设备，将原料送入输入总线正面；按配方比例供料，给每种粉末保留槽位。
- **物品输出**：从输出总线正面用管道、导管或传送带主动抽取，分别送往材料存储或下一台加工机器。
- **流体输入**：按流体种类分开管线和输入仓，检查过滤、锁定和储量；蒸汽供能管线接蒸汽仓。
- **流体输出**：从输出仓抽走产物，也可以让储罐对着输出仓，输出仓会自动输出。
- **编程电路**：固定生产一种材料时保持对应编号。更换配方前先停止供料、等待当前加工完成，再处理余料与剩余流体、调整电路。
- **仓室颜色**：初次搭建可以先不染色；染色后，要确保同份配方所需的物品、流体和电路仍能被同一输入组读取。

如果配方需要的物品种类超过一个总线的槽位，可以增加蒸汽输入总线；多种流体或较大的单轮用量也可能需要增加仓室。扩展接口时至少保留 25 个真正的外壳，也不能再加第二个蒸汽仓。

> [!WARNING]
> 需要完整收集产物时，把 GUI 中的溢出销毁设为“不销毁”，并为全部物品和流体提供输出空间。允许销毁流体后，未安装输出仓或输出仓堵塞时，盐水、王水等产物可能直接被丢弃。

## 故障排查

| 现象 | 检查内容 |
| --- | --- |
| 结构不完整 | 是否按占地 5×5、高 4 格搭建；控制器是否在正面第二层中央；框架、齿轮箱和管道方块是否按投影放置 |
| 提示结构等级不匹配 | 外壳、框架、齿轮箱和管道方块是否全部属于同一等级；是否只替换了部分青铜部件 |
| 缺少输入或输出接口 | 是否至少安装一种配方输入和一种输出接口；是否按配方同时安装所需的物品总线和流体仓室 |
| 缺少蒸汽仓或无法接入蒸汽总线 | 是否安装恰好一个蒸汽仓；是否误用普通电力机器的物品总线 |
| 加仓室后结构失效 | 是否保留至少 25 个真正的外壳；是否把框架、齿轮箱或管道方块换成了仓室 |
| 有粉末却找不到配方 | 原料形态、种类和比例是否符合 NEI；数量是否足够；电路编号是否正确；是否误看了其他机器的混合配方 |
| 放入流体单元后不能加工 | 是否查看了单方块配方；在无单元配方表中确认直接流体输入形式，再给普通输入仓供料 |
| 两种酸液齐全却不能制作王水 | 是否满足对应电路条件；两种流体是否分别进入普通输入仓；是否存在输出空间；仓室颜色是否使输入被分开 |
| 产出合金粉而没有合金锭 | 这是混粉配方的正常产物，按 NEI 安排后续冶炼 |
| 提示配方等级过高 | NEI 中的配方是否超过 LV；高压结构也不能处理 MV 及以上配方 |
| 只能低并行运行 | 每种原料和流体储量是否足够；仓室容量或输出空间是否限制单轮加工量；GUI 并行上限是否被调低 |
| 有物品产物却没有流体 | 是否安装普通输出仓；是否锁定了错误流体；是否开启流体溢出销毁；产物是否已被管道抽走 |
| 提示输出空间不足 | 是否给全部物品和流体留出空间；输出总线或输出仓是否堵塞，抽取和过滤设置是否正确 |
| 蒸汽仓有汽但运行后停机 | 持续供汽是否跟得上；管道是否受限或分流；当前并行和高压等级是否超过锅炉能力 |
| 箱子贴着总线却不传物品 | 蒸汽总线不会自动拉取或推出物品，检查主动输送设备及其连接面、方向和过滤 |

更多通用结构检查与工具操作见[多方块机器](./multiblocks_index.md)。
