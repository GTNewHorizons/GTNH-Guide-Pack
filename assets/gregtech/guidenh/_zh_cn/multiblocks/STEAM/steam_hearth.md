# 蒸汽壁炉

<GameScene interactive={true} wrap="square" align="right" width="320" height="280">
  <ImportStructureLib controller="gregtech:gt.blockmachines:31087" tier={1} />
</GameScene>

<ItemLink id="gregtech:gt.blockmachines:31087" showIcon="left" />（Steam Hearth）是蒸汽阶段的多方块熔炉，用蒸汽批量烧制物品，最多同时执行 8 份相同配方。它还可以切换为高炉或烟熏模式，分别加快适用的金属和食物配方。

蒸汽壁炉有普通青铜结构和高压钢结构两个等级，使用同一个控制器。机器不需要消耗电力，但要保证锅炉能够持续供给蒸汽。

| 项目 | 说明 |
| --- | --- |
| 解锁阶段 | 蒸汽；控制器配方需要高压蒸汽熔炉等材料 |
| 结构尺寸 | 3×3×3，控制器位于正面第二层中央 |
| 供能 | 恰好 1 个蒸汽仓，不使用能源仓 |
| 加工模式 | 熔炉、高炉、烟熏；具体可加工物品以对应配方为准 |
| 并行 | 最多 8 份相同配方；高压结构不增加并行上限 |
| 加工加成 | 普通结构的熔炉模式相对单方块青铜蒸汽熔炉有 125% 运行速度、62.5% 的每并行蒸汽消耗速率 |
| 升级与超频 | 高压结构使速度和蒸汽消耗速率翻倍；没有电压超频 |
| 维护与污染 | 不需要维护，不产生污染，也不需要消声仓 |

### 结构材料

下面按一个蒸汽仓、一个输入总线和一个输出总线的基础配置备料。普通结构使用青铜部件，高压结构使用对应钢制部件；**同一台机器的四类结构部件必须属于同一等级**。

| 管道方块 | <ItemLink id="gregtech:gt.blockcasings2:12" showIcon="left" /> | <ItemLink id="gregtech:gt.blockcasings2:13" showIcon="left" /> | 4 个，底层四边中央 |

| 控制器 | <ItemLink id="gregtech:gt.blockmachines:31087" showIcon="left" /> | 同一控制器 | 1 个，正面第二层中央 |

| 输入总线 | <ItemLink id="gregtech:gt.blockmachines:31046" showIcon="left" /> | 同一总线 | 至少 1 个，替换外壳位置 |
| 输出总线 | <ItemLink id="gregtech:gt.blockmachines:31047" showIcon="left" /> | 同一总线 | 至少 1 个，替换外壳位置 |

### 逐层放置

先铺底层，再放控制器所在的中层，最后放顶层的四个齿轮箱。投影中的空位不用补成实心外壳，结构也不要求玻璃或加热线圈。

将蒸汽仓和蒸汽专用输入、输出总线放在合适的外壳位置，方便管道连接。普通电力机器的输入、输出总线不能代替蒸汽专用总线，也不需要安装维护仓或消声仓。

使用 <ItemLink id="structurelib:item.structurelib.constructableTrigger" showIcon="left" /> 可以查看结构投影并辅助搭建。投影仪的主信道等级 1 对应普通结构，等级 2 对应高压结构；辅助搭建后仍需安装仓室、检查结构。

## 用途与加工模式

蒸汽壁炉可以批量烧制有熔炉配方的物品，例如石头、玻璃、可直接熔炼的材料和熟食。不同输入对应的产物可能不一样，烧制前先用 NEI 确认配方，尤其不要把矿物处理路线中的中间产物直接烧掉。

用 <ItemLink id="gregtech:gt.metatool.01:22" showIcon="left" /> 右键控制器，可以按“**熔炉 → 高炉 → 烟熏 → 熔炉**”循环切换，也可以使用 GUI 中的模式按钮。Waila 和控制器界面可以查看当前模式。

| 模式 | 适用配方 | 相对本级结构熔炉模式的变化 |
| --- | --- | --- |
| 熔炉（Furnace） | 普通熔炉配方 | 基础速度与蒸汽消耗速率 |
| 高炉（Blasting） | Et Futurum 高炉认可的金属类配方 | 速度翻倍，蒸汽消耗速率翻倍 |
| 烟熏（Smoking） | Et Futurum 烟熏炉认可的食物类配方 | 速度翻倍，蒸汽消耗速率翻倍 |

高炉和烟熏模式只处理各自配方表中的物品，不会自动退回普通熔炉模式。放入有普通熔炉配方的物品却不工作时，先检查模式；不能仅凭“这是金属”或“这是食物”判断一定存在专用配方。

> [!NOTE]
> 这里的“高炉”是 MC 1.14+ 的高炉加工模式，不能代替[工业高炉](../LV/electric_blast_furnace.md)或砖高炉。它没有炉温和线圈机制，不会因为换到高炉模式就能执行工业高炉配方。

### 首次运行

1. 完成结构检查，确认蒸汽仓、蒸汽输入总线和蒸汽输出总线均已安装。
2. 给蒸汽仓接通蒸汽管道，确认蒸汽能够实际进入仓室。
3. 选择输入物品对应的模式，在输出总线中留出空间。
4. 开机并投入少量原料，观察产物去向和蒸汽仓储量。
5. 确认持续供汽后，再增加原料和并行数量。

## 供汽与产能

蒸汽壁炉最多同时执行 8 份**同一种配方**，不代表能在一轮中同时烧制 8 种不同物品。实际并行数量还受原料数量、输出空间和 GUI 中的并行上限设置影响。

普通结构熔炉模式的运行速度是单方块青铜蒸汽熔炉的 125%，耗时约为其 80%；每并行的蒸汽消耗速率为其 62.5%。速度和蒸汽消耗速率一起计算后，处理同一份物品的总蒸汽量约为其 50%，但整台机器同时运行多个并行时，瞬时蒸汽消耗量仍会增加。

下面以**普通结构的熔炉模式、相同并行数量**为基准，比较升级和模式变化：

| 结构与模式 | 运行速度 | 蒸汽消耗速率 |
| --- | --- | --- |
| 普通结构，熔炉 | 1 倍 | 1 倍 |
| 普通结构，高炉或烟熏 | 2 倍 | 2 倍 |
| 高压结构，熔炉 | 2 倍 | 2 倍 |
| 高压结构，高炉或烟熏 | 4 倍 | 4 倍 |

模式加速和高压加速可以叠加。它们都把速度和蒸汽消耗速率一起提高，因此主要增加吞吐量，不会再把单份物品的总蒸汽消耗量减半；具体耗时和蒸汽消耗量还会受到 tick 与整数取整影响。

规划锅炉和管道时，要按**运行时的蒸汽消耗速率**供给，不能只看蒸汽仓的 64,000 L 容量。

可通过 Waila 查看运行时蒸汽消耗速率，并观察蒸汽仓在连续加工时是否持续下降。若界面使用 L/t，正常 20 TPS 下乘以 20 即为 L/s；比较管道吞吐量时也要统一单位。供汽不足时，可以在 GUI 中降低并行上限，再扩充锅炉产能或改善管道。

> [!WARNING]
> 加工期间蒸汽不足会使当前加工中止，已经投入的原料不会返还。升级高压结构或切换加速模式前，先检查蒸汽产量和管道速率。

## 升级高压结构

</GameScene>

高压结构的尺寸、仓室位置和控制器不变，但要把镀铜砖块、青铜齿轮箱、青铜管道方块和青铜燃烧室**全部换成表中的对应钢制部件**。只换外壳、只换燃烧室，或把两种等级的材料混用，都不能通过等级检查。

升级前先停止加工和原料输入。完成替换后重新检查结构，确认机器显示为高压等级，再恢复供汽和生产。

高压是机器的结构等级，不是一种额外的蒸汽流体。它仍使用普通蒸汽，原有蒸汽仓和蒸汽总线可以继续使用；也不需要改装电力能源仓。升级后速度和蒸汽消耗速率翻倍，但最大并行仍是 8。

## 自动化与分流

蒸汽输入总线和蒸汽输出总线各有 4 个物品槽。它们不会自动从相邻箱子取料或把产物推入箱子，单纯贴着箱子放置并不能完成自动化。

- **输入**：使用漏斗、GT 物品管道、传送带或物品导管等设备，将物品送入输入总线正面。
- **输出**：从输出总线正面用管道、导管或传送带主动抽取，再送往存储或下一台机器。
- **蒸汽**：用流体管道把锅炉输出送入蒸汽仓，物品总线不能接收蒸汽。
- **分流**：给输送设备按实际原料设置过滤，避免当前模式不能处理的物品占满输入槽。

如果经常需要同时处理金属、食物和其他材料，可以分别配置机器或在换料时切换模式。增加输入总线能扩大物品缓冲，但不会增加并行上限；增加输出总线则能减少输出堵塞。

## 故障排查

| 现象 | 检查内容 |
| --- | --- |
| 结构不完整 | 控制器是否在正面第二层中央；四个齿轮箱、四个管道方块和三个燃烧室的位置是否正确 |
| 提示结构等级不匹配 | 外壳、齿轮箱、管道方块和燃烧室是否全部使用同一等级；是否只替换了部分青铜部件 |
| 缺少蒸汽仓或总线 | 是否安装恰好一个蒸汽仓及至少各一个蒸汽输入、输出总线；是否误用仓室 |
| 加总线后结构失效 | 是否保留至少两个真正的外壳；是否把齿轮箱、管道方块或燃烧室位置换成了总线 |
| 有原料却找不到配方 | 当前模式是否正确；物品是否确实有该模式的配方；输出空间是否足够 |
| 蒸汽仓有汽但运行后停机 | 持续供汽是否跟得上；管道是否受限或分流；当前并行、高压等级和加速模式是否超过锅炉能力 |
| 箱子贴着总线却不传物品 | 蒸汽总线不会自动拉取或推出物品，检查主动输送设备及其连接面、方向和过滤 |
| 实际加工数量不到 8 份 | 原料是否为同一种配方且数量足够；并行上限是否被调低；输出槽是否能容纳全部产物 |
| 升级后蒸汽消耗明显增加 | 高压使蒸汽消耗速率翻倍；高炉或烟熏模式还能再翻倍，应相应提高供汽能力 |

更多通用结构检查与工具操作见[多方块机器](../multiblocks_index.md)。
